## 3. W-V2 수직 슬라이스 — P0 범위

원문 §97 + 레퍼런스 분석 §21 통합 정본:

1. **정확성**: W-FIX 완료 전제.
2. **턴 구조**: EDIT → ON AIR → BREAK(매 턴) → CLEANUP. 셔플과 `NEW` 귀환 포함.
3. **TX/RX + CUE 1**: CARRIER 양면 지정(ADR-0007), 첫 3턴 추천 표시.
4. **SYNC 0~3**: 안전장치 포함 최소 구현.
5. **카드 8장**: 2400 / 14K / MULTI / CACHE / FIREWALL / CHAT / VOICE / NOISE (+BREAK에 NØA BOOST 1종, `BREAK_CONTRACT` phase — 구매 즉시가 아니라 다음 EDIT 시작 시 1회 발동, [15](15_CARDS.md) §1·§7).
6. **적 의도 4종**: BOT RAID / MUTE / GIFT DROP / MIRROR. 적은 BOT.CHAT / POP.AD / SPON.GIFT / MOD.MASK.
7. **64칸 논리 링 + 16칸 임시 표시**: 링 데이터 모델은 처음부터 64칸 `EchoCell{origin,state}`([10](10_MECHANICS.md) §8)로 구현하되, P0 렌더러는 16대구간 요약만 그린다 — 3색 집계 + 임시 결과 화면 (64칸 완전 UI·엔딩 분기 없음). 데이터가 64인 이유: 나중에 렌더러만 교체하면 되고, 검증 질문의 색 비율 계산이 P0부터 최종 수치와 같은 기반 위에서 돈다.
8. **TREND MIRROR 1종**: 최다 사용 PROGRAM 하나만 복제.
9. **OPEN CHANNEL**: 덱 컴파일 모델 검증([10](10_MECHANICS.md) §10) — CHAT·VOICE 두 ARCHIVE만으로도 "진입 시 컴파일 → CARRIER 자동 TX → ARCHIVE 고정 박자 자동 발동 → Space가 최종 프로토콜만 발동"의 전 과정이 실제로 도는지 확인한다. 개별 카드 재선택 UI가 없어도 게임이 성립하는지가 P0의 핵심 리스크다.
10. **아트 병행 트랙** ([41](41_PIXEL_ART.md) §7 단계 0~3): 팔레트·실루엣·에코 모델 시트·24×24 애니·카드 UI·아이콘 8종 — 코드 슬라이스와 같은 기간에 진행, 16×16 vs 24×24 A/B 데이터 확보.

P0 제외 명시: 시크 정식 보스(케이블·눈 실루엣만 임시) / 64칸 완전 UI / 엔딩 4종 / 시간층(1개 고정) / 저장·해금 / 전체 카드 / 최종 키아트 / 공간 해시 / 자산 압축 / Sokol / 셰이더.

P0가 답해야 하는 질문 (GV2의 사람 문항이 이것이다):

- 한 손패에서 실제 고민이 생기는가? (같은 손패·다른 의도 → 다른 CUE)
- **TX/RX 배분이 실제로 갈리는가?** (구절의 ≥30%, 전부 TX·전부 RX가 상시 정답 아님)
- 수동 발동이 이동 흐름을 망치지 않는가?
- 구매 카드가 돌아올 때 기쁜가?
- ARCHIVE의 초반 불편함이 후반 힘으로 반전되는가?
- 노아 복제가 기억에 남는가? (색상 변경이 아니라 의미 반전으로)
- (아트) 에코가 작은 화면에서 즉시 식별되고, 음소거로 세 카드 발동을 구분하는가?

## 4. 게이트

### GV2 — go/no-go (8/02)

정량 (SIM): BIG_BAUD·ECHO_RUSH·LOOP_ENGINE 3봇 × 30시드에서 크래시 0, 2봇 이상 승리 가능. 정성 (사람 5명, 슬라이스 2런): §3의 5질문에 대해 —

- **go**: 7질문 중 5개에서 3/5 이상 긍정, 특히 "한 손패 고민"과 "반전"은 필수 통과. TX/RX·아트 문항은 go/no-go가 아니라 방향 수정 신호(실패 시 해당 축만 재작업).
- **no-go**: "한 손패 고민" 또는 "수동 발동" 문항이 2/5 이하 — 코어 가설 기각. V1 복귀.
- 판정 불가(테스터 수급 실패)면 **보수적으로 no-go** — V1은 이미 검증된 게임이다.

## 7. 열린 질문 추적 — 원문 부록 F

프로토타입 전 문장으로 답해야 하는 18문 중 본 개정에서 시드 답이 정해진 것: F4(청록 생성 = ARCHIVE 발동, B2-링) / F5(자홍 = 능동 선택 + OC 피격 전환 둘 다) / F6(호박 = 거래 +2, LAST_ARCHIVE 봇으로 검증) / F7(링 상시 노출) / F8(색이 엔딩과 최종 기술 모두 결정 — 프로토콜은 ARCHIVE 타입, 엔딩은 색) / F9(CUE 1) / F10(카드별 혼합) / F11(BREAK 매 턴) / F12(12턴×8초) / F13(TREND = 수동 발동 횟수) / F14(자랑으로 연출) / F17(공모전판: 엔딩 4·저장·해금 최소 — 삭제 순서 §2) / F18(go/no-go 게이트로 결정).

**서사 질문으로 남는 것** (제작진이 문장으로 답하되 게임은 침묵): F1 에코의 방송은 언제부터 반복되었는가 / F2 노아는 에코보다 먼저인가 / F3 시크의 "앞선 세 번"은 루프인가 저장본인가 / F15 시크 경로의 플레이 스타일 독립성 / F16 메아리의 인간 여부 불명 상태의 만족도 — F15·16은 G2′ 문항으로 측정.
