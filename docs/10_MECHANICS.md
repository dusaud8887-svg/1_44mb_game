# 10 — 규칙 명세

플레이 규칙의 정본. 모든 튜닝 수치는 [20_BALANCE.md](20_BALANCE.md)의 표 ID로 참조하고 여기 중복 기재하지 않는다. 각 절 끝의 `[구현]` 표기는 2026-07-14 [src/echo144.c](../src/echo144.c) 기준 검증 상태다.

## 1. 플레이 흐름

```text
[타이틀] ENTER 일반 / F2 TODAY
   ↓
[오늘의 채널] 킹덤 5종 + 지침 1종 확인. 시간 제한 없음
   ↓
[준비 방송 DEAD AIR] 5장 탄창 자동 실행 → 이동·SEEK → 손패 정리 → 다음 5장
   ↓ 첫 접속 후 일정 간격, 현재 손패 종료 후 (B-시간)
[접속실 09 NODE — 완전 정지] 다음 5장 공개 → B 합으로 1장 구매/패스
   ↓ 조기 GO LIVE 창(B-시간) 또는 강제
[마지막 방송 LAST LIVE] 무음 조각이 공격+SIGNAL로 반전, 64 대 FORMAT 레이스
   ↓
[결과] 총 시간/LIVE 시간/HP/최종 덱/지침/seed → 즉시 재시작
```

- NODE에서 보낸 현실 시간은 전투 시계에 포함하지 않는다.
- LAST LIVE 중에는 NODE가 열리지 않는다.
- TODAY는 로컬 날짜 `YYYYMMDD` 고정 시드. 같은 날짜면 같은 킹덤·지침·셔플·웨이브. 서버·저장 없음.

`[구현 ✅]` 전 흐름, TODAY 결정론 리플레이 selftest 통과.

## 2. 덱·손패·SEEK

1. 시작 상태는 B-시작 표를 따른다. 드로우 더미를 셔플하고 5장을 탄창에 공개한다.
2. 왼쪽 첫 카드가 발동하고 버림더미로 가며, 남은 카드가 당겨진다. 5장이 끝나면 새 손패 5장을 뽑는다.
3. 드로우 더미가 부족하면 남은 장을 뽑고 버림더미를 셔플해 채운다. 셔플은 손패 영역 스윕과 FDD 시크음으로 보인다.
4. 구매 카드와 BAD.SECT는 버림더미로 들어가 **다음 셔플 뒤에** 나타난다. 즉시 강화는 없다.
5. **SEEK (SPACE)** — 손패당 1회, 아직 발동하지 않은 첫 카드를 그 손패 맨 뒤로 보낸다. 버리기·드로우가 아니므로 오염을 지우지 않고 순서 결정 한 번만 돌려준다. 사용하지 않아도 정상 플레이 가능해야 한다.
6. 덱 최소 5장, 최대 40장(B-덱). 초과 시 구매 불가.

`[구현 ✅]` 전 항목. SEEK는 PREFETCH 예약과의 상호작용(비조각이 앞으로 오면 대기 복원)까지 처리됨.

## 3. NODE 경제

```text
이번 구매력 = NODE 진입 시 공개한 다음 5장의 buy 값 합
이월 없음 / 기본 구매 1회 / 처치 재화 없음
```

1. 첫 접속 시각과 이후 간격은 B-시간을 따른다. 예약 시 현재 손패를 끝까지 처리한 뒤 다음 5장을 뽑고 완전 정지한다.
2. 상점에는 기본 공급 5종 + 이번 킹덤 5종을 모두 표시하되, 현재 B로 살 수 있는 카드만 정상 밝기·기본 커서 순환. TAB으로 전체 열람.
3. 구매 시 카드는 버림더미로. 킹덤 카드 구매는 INDEX 지침 카운터에 종류를 기록한다.
4. **DEFRAG.EXE는 상점 서비스** — 구매 1회를 소비해 공개 구매 손패 5장 중 1장을 즉시 폐기하고, 자신은 덱에 들어가지 않는다. 폐기 후 덱 5장 미만이 되는 선택은 불가.
5. GO LIVE 창이 열린 NODE에서는 `F`로 구매를 포기하고 즉시 LAST LIVE 진입. Y/N 확인 1회. 조기 진입의 전투 보너스는 없다 — 보상은 가장 위험한 후반 구간을 건너뛰는 생존과 기록 단축뿐이다.
6. 상점 종료 후 공개했던 손패를 그대로 실행한다.

경제 삼각관계: 모뎀(현재 공격+미래 구매력) / 유틸(현재 전투, B 0 희석) / 조각(모두 희석, LIVE의 공격+SIGNAL). 이 셋 중 무엇도 자동 정답이면 실패다.

`[구현 ✅]` 전 항목. `[구현 ⬜]` 첫 NODE의 조각 회색→자홍 미리보기(§7-1 약속)는 미구현 — `card_box(live_preview)` 인자만 존재. W5에 연결.

## 4. 카드 해석 순서와 상한

구현 분쟁 방지용 고정 규칙. 카드 목록·효과·수치는 B-카드.

1. 카드를 실행 슬롯으로 옮겨 처리한 뒤 버림더미로 보낸다. PATCH.TMP만 폐기(덱 5장 미만이 되면 예외적으로 버림더미 유지).
2. MULTI는 다음 실물 카드 1장의 대기시간만 0으로 만들고 복제하지 않는다.
3. 피해를 낸 카드 처리 시 `last_payload`(피해·넉백·표식)를 저장한다. MACRO는 그 값만 70%로 실행하고 buy·SIGNAL·무적·PREFETCH 예약은 복사하지 않는다.
4. MACRO→MACRO는 같은 `last_payload`를 재사용하며 자신의 70% 결과를 재저장하지 않는다.
5. PREFETCH 예약은 1개만 유지, 중복 발동은 갱신. LIVE 중 예약된 조각의 실물 발동에만 SIGNAL +1.
6. PATCH.TMP 자기 폐기와 엘리트 보상의 BAD 제거는 CLEAN 지침에 세지 않는다. 플레이어의 DEFRAG 폐기만 센다.
7. 자연 조합이 실제로 성립했을 때만 LINK!를 표시한다. 레시피·진화·카드 생성 없음.
8. 한 카드 발동의 추가 피해 이벤트는 최대 8개. 초과는 버린다.
9. LAST LIVE 전환은 현재 손패를 갈아엎지 않는다. 다음 발동 조각부터 새 효과와 SIGNAL.

`[구현 ✅]` 1~7, 9 — selftest에 MACRO 비복사, PREFETCH +1·소거, PATCH 최소 덱 단언 포함. 8은 구조적으로 만족(재귀 경로 없음)하나 명시적 상한 코드는 없음 — 새 효과 추가 시 재확인.

## 5. 전투·적·웨이브

1. 내부 320×240, 전투 영역 320×192, 하단 48px HUD. 카메라 없음, 플레이어·적은 영역 밖으로 나가지 않는다.
2. WASD/방향키 8방향, 대각선 정규화. 공격은 최근접 적 자동 조준, 대상이 없으면 마지막 이동 방향.
3. 적 4종의 행동(B-적): WORM 직진 / POPUP 사인파 접근 / TROJAN 저속·사망 시 WORM 3분열 / RANSOM 거리 유지·저속탄. RANSOM 탄 피격은 HP 대신 BAD.SECT 1장 삽입, 이후 오염 면역 시간과 BAD 상한은 B-적.
4. 3:00 엘리트 SEEK.WRM은 새 AI가 아니라 RANSOM 변형(배율 B-적). 처치 시 BAD 1장 제거 + PATCH.TMP 1장을 버림더미에. 보상 선택창 없음.
5. 스폰은 초당 예산(B-스폰)을 적 비용으로 소비한다. 구간별 활성 적과 혼합 비율은 B-스폰. 동시 적 상한 256.
6. CHKDSK 상자가 주기적으로(B-시간) 반대편에 생성, 부수면 HP 1 회복. 이동 동기를 만드는 유일한 오브젝트.
7. 난이도는 적 HP 인플레가 아니라 공간 문제의 종류와 밀도로 올린다. LIVE는 새 적을 가르치지 않고 속도·비율만 올린다(B-스폰).

`[구현 ✅]` 전 항목.

## 6. LAST LIVE — 승리·실패·버스트

GO LIVE 실행(한 호흡): 짧은 정지 → LIVE 링 점등·팔레트 반전 → FORMAT/0 `UNSUPPORTED TIMESTAMP` 표시 → 적·탄 넉백으로 읽기 공간 확보 → SIGNAL을 지침 선송출 값에서 시작 → FORMAT 게이지 60초 증가 시작.

```text
승리:   A:\ SIGNAL ≥ 64
실패 A: FORMAT ≥ 100%   실패 B: HP = 0
동일 틱: 카드/SIGNAL을 먼저 처리 — 64 도달이 우선
```

1. 조각 실물 카드 발동 시 SIGNAL을 올리고 동시에 AOE를 낸다. 일반 공격·MACRO 복사는 SIGNAL을 올리지 않는다.
2. SIGNAL 16/32/48에서 **캐리어 버스트** 1회씩: 화면의 적탄 전부 제거 + 적 넉백. 피해·SIGNAL 추가 없음 — 예상 수식을 바꾸지 않는다. 한 카드가 여러 문턱을 넘으면 낮은 순서로 각 1회.
3. HUD 예상치 `A:\ SIG`는 보수 계산(B-공식): MULTI 단축·PREFETCH +1 제외, `≥N/64`로 표시해 거짓 정밀도를 피한다. 이 값은 생존을 보장하지 않는다.
4. FORMAT/0은 새 보스 패턴이 아니라 게이지와 초상으로 존재하는 시스템 보스다. 상대는 세 층의 공개 오토마: FORMAT 마감 / 시간표 웨이브 / RANSOM·SEEK의 덱 오염.

종결 5박자: 내가 켠 방송 → 무음의 반전(같은 손패 위치에서 회색→자홍) → 계단식 접수(3회 버스트) → 가속되는 송출(1/3/6 패킷의 다른 음정) → 짧은 정적(64 도달 시 급정지, NO CARRIER 2.5초).

실패 표기: LIVE 전 사망 `CARRIER LOST — CURRENT OUTPUT LOW` / FORMAT 선착 `SIGNAL N/64 — DEAD AIR`. 정답 빌드는 알려주지 않되 원인은 숨기지 않는다.

결과 도장(비영구): `조기 방송`, `클린 송출`, `30초 송출`(판정치 B-도장), 셋 동시 달성 시 `에코/144` + 1프레임 `시청자 2`. 미달성 슬롯은 표시하지 않는다 — 64 성공을 미완성처럼 만들지 않는다. ENCORE·무한 모드 없음.

`[구현 ✅]` 전 항목 — 동일 틱 우선, 버스트 1회성, 도장 경계값, 저자극 모드 무플래시까지 selftest 단언.

## 7. UX·온보딩·접근성

### 7-1. HUD 불변 조건

- DEAD AIR 상단: HP / 전투 시계 / NOW / `신호 ≥N/64`. LIVE 상단: `송출 신호 N/64`와 `종료 진행 N%`의 반대 방향 막대 + LIVE 링 4분원.
- 카드는 2~4자 한글 라벨 + B 값 + SIG 값. 색만으로 구분하지 않는다(무음 `…`/BAD `X` 병기).
- 발동 카드에서 실제 탄환이 출발하는 궤적 표시 — `카드→공격→버림` 인과 연결.
- 셔플 스윕, LINK!, SEEK 슬라이드는 각각 고유 피드백. 무음 조각 발동은 수치 상승 없이 펄스만.
- 첫 NODE에서 같은 조각 카드의 회색/자홍 전후 미리보기 1회 — 본질적 반전을 미리 약속. `[구현 ⬜ W5]`

### 7-2. 온보딩 — 3문장 상한

1. `아래 5장이 왼쪽부터 자동 실행됩니다.` (첫 시작)
2. `모뎀은 지금 강하고, 조각은 LIVE에서 송출.` + `다음 5장의 B 합으로 1장만 받습니다.` (첫 NODE)
3. GO LIVE 첫 등장 때 `한 구매를 포기하고 마지막 방송` 한 줄.

시대 모순·파일 포맷·세계관은 튜토리얼에서 설명하지 않는다. 지침은 채널 화면의 한 줄 설명으로만.

### 7-3. 접근성·안전

- `M` 즉시 음소거, `F1` 저자극(플래시·흔들림 0, 규칙 불변), `ESC` 일시정지, Alt+F4 정상 종료.
- 백색 플래시 최대 2프레임, 흔들림 최대 2px. 오염 노이즈는 고정 패턴, 빠른 점멸 금지.
- 층 분리 원칙: 초보는 "움직이면 되고 5장이 알아서 나간다"만, 숙련자는 손패 구절·B 계산·셔플 추적·조기 종결을 동시에. 난이도는 규칙 은닉이나 버튼 추가로 만들지 않는다.

`[구현 ✅]` 7-2, 7-3 전 항목.
