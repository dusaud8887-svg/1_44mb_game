# 40 — 아트·사운드·텍스트

표현 계층의 정본. 레퍼런스 조사(Helltaker·Touhou·타깃 훅 판정)는 [archive/ECHO_144_FINAL_SPEC.md](archive/ECHO_144_FINAL_SPEC.md) §10에 동결. 톤 배분 원칙: **명랑 70 / 어긋남 20 / 어둠 10** — 계측값이 아니라 편집 원칙이다.

## 1. 아트 방향 — 금지가 절반이다

시각 문법: 일본식 상업 캐릭터 디자인의 명료한 포즈·셀 색면 + 한국 90년대 PC 안내문의 건조함 + 미래 파일의 **국소** 오류. 어느 실제 작품·서비스·OS도 재현하지 않는다.

금지: 교복·메이드·고양이귀·바디슈트 등 흔한 사이버 미소녀 기호 / 화면 전체 VHS·스캔라인 필터(오류는 카드 한 장, 끊긴 링 한 조각, 한 프레임의 잘못된 연도로만) / 국가 상징·일본 문자 / 노출·장식 밀도로 만드는 후킹.

캐릭터 핵심은 장식 목록이 아니라 `비대칭 1곳 + 강조색 1개 + 반복 도형 1개`. 16×16에서 사라지는 설정은 핵심 디자인이 아니다.

| 캐릭터 | 색 | 도형 | 동사 | 실루엣 |
|---|---|---|---|---|
| 에코 일사사 | 청록(+빨간 LIVE 핀) | 끊긴 원형 링 | 송출한다 | 흰 비대칭 재킷, 청록 머리 |
| 시크 웜 | 호박 | 깨진 버퍼 링·리본 케이블 | 붙잡는다 | 낮고 둥근 검정 |
| 포맷 제로 | 자홍 | 진행 막대 베일 | 닫는다 | 길고 수직인 검정 제복, 흰 장갑 |

모션 문법(각 4프레임 상한, 반전·오프셋·팔레트 교환으로): 에코는 새 손패 때만 1px 튀고 링이 반 박자 늦게 따라온다 / 시크는 피격 시 가로 1px 눌리고 케이블이 반대로 휜다 / 제로는 걷지 않고 수직 1px 미끄러지며 베일 막대만 줄어든다.

## 2. 팔레트와 화면 상태 — 실측 기준

현재 코드의 9색이 논리 팔레트의 시드다. 확장은 16색 상한.

| 이름 | HEX | 용도 |
|---|---|---|
| BG | `100d18` | 배경 (LIVE: `130918`) |
| PANEL | `201c2b` | HUD·카드 바탕 |
| WHITE | `f2f0e6` | 본문·활성 카드 |
| DIM | `7b7b86` | 보조·무음 조각 |
| CYAN | `4ddbc8` | DEAD AIR 기조·에코 |
| AMBER | `e5a84b` | B 값·시크·셔플 |
| MAGENTA | `ed4f9a` | LIVE 기조·제로·조각 반전 |
| BLUE | `6da9e8` | TROJAN |
| RED | `e55b57` | 위험·RANSOM·BAD |

상태 대비: DEAD AIR = 청록/호박, LAST LIVE = 자홍/청색/흰색. 같은 카드가 회색 `…` → 자홍 `S값`으로 바뀌는 것이 제품의 얼굴이다.

## 3. 아트 제작 파이프라인 (W5)

`[구현 ✅ 2026-07-15]` 프로시저럴 블록아웃(draw_echo/seek/format)을 2bpp 픽셀 아트로 교체 완료 — 16×16 8프레임 + 초상 48×48 3장(2,240B), 타이틀·GO LIVE 전환은 초상 사용. 상세와 남은 후속은 [41_PIXEL_ART.md](41_PIXEL_ART.md) §8.

제작 규격·기법·공정·수용 기준의 정본은 **[41_PIXEL_ART.md](41_PIXEL_ART.md)**다. 요약: Claude가 `.px` 그리드로 그리고 `tools/px_render.ps1`로 렌더한 PNG를 직접 육안 검수하는 반복 루프. PC-98 문법(디더는 초상에만)과 실루엣 우선 원칙, 캐릭터별 3색 램프(공용 어둠·광 + 강조색 1). 규격: 플레이어·네임드 16×16 4프레임 이내, 초상 48×48 2bpp 3장, 합계 4KB 이하. 타이틀은 세 초상과 로고 재배치, 배경은 검정/남색 PCB 선 + 큰 A:\ 원 1장 유지.

## 4. 사운드

P0: `waveOut` 22.05kHz 모노, 사각파 2 + 노이즈 1 + SFX 1보이스. **음악이 W5까지 불안정하면 SFX만 제출한다.**

- 캐리어 버스트는 채널을 늘리지 않는다: 16에서 저음 사각파 합류 → 32에서 노이즈 리듬 촘촘 → 48에서 주선율 한 옥타브 상승 → 64에서 세 채널이 차례로 끊긴다. `[구현 ✅ 근사]` — 현재 주파수 스위칭으로 동작, W5에서 음계화.
- **3음 모티프 `[구현 ✅ 2026-07-14]`**: 모티프 `E4–G4–B4`. 에코 = 정방향(런 시작·승리는 한 옥타브 위 E5–G5–B5), 시크 = 역방향 `B4–G4–E4`(엘리트 등장·PATCH 보상), 제로 = `B4` 단음 반복(GO LIVE 전환·FORMAT 75% 경고). 관계를 음으로 암시하고 대사로 설명하지 않는다.
- SFX 어휘: 약탄/강탄(모뎀 등급이 높을수록 낮고 두꺼운 음고 — 2400=300Hz→56K=180Hz), 무음 캐리어 노이즈(짧고 작게), 셔플 FDD 시크, 구매, 피격, SIGNAL 3등급 음정(카드 가격 비례), GO LIVE, NO CARRIER. `M` 즉시 음소거. `[구현 ✅ 2026-07-14]`

## 5. 텍스트·네이밍 — 동결

원칙: 한국어 먼저, ASCII는 작은 보조 라벨. 일본 문자·`~데스`류 흉내 금지. 혼합감은 와세이 에이고식 상업 합성어(`56K 맥시멈`, `세이프 월`)와 과잉 정중한 안내문(`불편을 드려 유감이며, 예정대로입니다.`)의 온도 차로 만든다. 언어 혼합 자체를 해독해야 웃기는 문장은 삭제. 노출 면적 상한: 한국어 80 / 한글 표기 외래어 15 / ASCII 5.

화면 표기(타이틀 `에코/144 — LAST LIVE`, `오늘의 채널`, `접속실 09`, `송출 신호 N/64`, `종료 진행 N%`, `시청자 1`)와 카드 한글명 19종은 코드 `CARD[]` 및 draw_* 문자열이 정본. `[구현 ✅]`

### 고정 대사 9줄 `[구현 ✅]`

```text
에코  시청자 한 분! 오늘도 만석 감사입니다. / 다음 장면, 뒤로 부탁합니다. / 조금 이르지만, 지각보단 라이브!
시크  첫 방송 축하드립니다. 저는 세 번째부터 봤습니다. / 빠진 장면은 임시 보관입니다. 영구적으로. / 깨진 건 아직 남아 있다는 뜻입니다. 대체로.
제로  지원되지 않는 시간입니다. 정상 종료를 시작합니다. / 불편을 드려 유감이며, 예정대로입니다. / 시청자 수는 정정하지 않겠습니다.
```

### 로그 조각 8개와 노출 규칙 `[구현 ✅]`

01 접속 혼잡(明) / 02 1997년 미판매(明) / 03 STAFF 0(謎) / 04 대피 안내 [CUT](暗) / 05 관람 완료 ×3(謎) / 06 모두 돌아온 날 00:00(暗) / 07 다음 방송: 어제(明) / 08 엔딩 멘트 하지 마(暗). 한 런에 시드로 밝은 것 1 + 무거운 것 1만, CHAT 발동 2·5회째에 노출. 무거운 문장 2연속 금지.

### 확정 사실 4개 / 답하지 않을 질문 3개

확정: 1997년 NODE 09에 미래 포맷 조각이 도착했다 / ECHO는 끊기기 전 64를 보내려 한다 / SEEK는 조각을 모으며 ECHO를 이전부터 본 듯하다 / 성공해도 시청자는 1이고 곧 NO CARRIER다.

불답: ECHO는 실제 방송인가 만들어진 인격인가 / SEEK는 악성 팬인가 유일한 시청자인가 이전 ECHO인가 / 시청자 1은 누구인가. **새 로그로 답하지 않는다. 도감·해금률 없음.**

### 서사 전달률 (신규 원칙)

미스터리의 운반체가 1.2초 대사와 런당 로그 2개뿐이므로 전달은 공짜가 아니다. G2에 도달률 문항을 넣고([50_PRODUCTION.md](50_PRODUCTION.md) §3), 미달 시 로그를 늘리지 않고 **노출 시점**(전투 밀도가 낮은 NODE 직후 1초)으로 옮긴다.
