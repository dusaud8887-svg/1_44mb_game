ECHO/144 플레이테스트 안내

1. ECHO144_DEBUG.EXE를 원하는 폴더에 풀고 실행합니다. 설치와 네트워크 연결은 없습니다.
2. Windows SmartScreen이 표시되면 게시자를 확인한 뒤 "추가 정보 > 실행"을 선택합니다. 실행이 불안하면 중단하고 테스트 담당자에게 알리세요. 보안 기능을 끄지 마세요.
3. 조작: 방향키/WASD 이동, Enter 선택, Tab 다음 단계, Space 송출/카드 찾기, Esc 일시정지, M 음소거, F1 저자극.
4. F6~F9는 개발용 치트키입니다. 정상 테스트에서는 누르지 마세요.
5. 종료 후 같은 폴더의 playtest_v2.csv를 담당자에게 전달합니다. 파일에는 익명 게임 시드, 상태 전이, 선택 요약, 체력과 결과만 기록되며 이름·키 입력 원문·PC 정보는 기록하지 않습니다.
6. 삭제하려면 압축을 푼 폴더를 지우면 됩니다. 별도 설치 항목은 없습니다.
