## 1. 제품 약속

플레이어가 30초 안에 이해해야 하는 네 문장:

1. 화면 아래 5장이 순서대로 자동 발사되는 탄창이다.
2. 모뎀 카드는 현재 전투와 다음 구매를 강하게 한다.
3. 방송 조각은 지금은 무음이지만 LAST LIVE에서 폭발하고 SIGNAL을 보낸다.
4. 따라서 지금 버틸 엔진, 64패킷을 보낼 조각, 언제 방송을 시작할지를 함께 판단한다.

한 문장 차별점: **도미니언의 5장 손패가 실시간 탄창이 되고, 무음 방송 조각이 LAST LIVE의 총알이자 승리 게이지로 뒤집힌다.**

## 2. 재미 명제 — 쾌락 → 기능 → 검증

도미니언 플레이어가 반복해서 말하는 다섯 가지 즐거움을 기능과 게이트에 1:1로 묶는다. 기능이 쾌락을 만들지 못하면 기능을 고치고, 게이트가 쾌락을 측정하지 못하면 게이트를 고친다.

| 쾌락 | 운반 기능 | 검증 게이트(50 §3) |
|---|---|---|
| 발견 — 두 카드가 한 손에서 맞물림 | LINK! 피드백 3쌍 (PREFETCH→조각, MARKER→SURGE, MULTI→MACRO) | G2: LINK 경험자가 조합을 말로 재현 |
| 통제감 — 약한 카드를 없앤 뒤의 순환 | DEFRAG 폐기, 덱 최소 5장 | G2: 폐기 전후 차이를 체감했다고 답변 |
| 작은 체크포인트 — 셔플마다 덱이 나아짐 | 셔플 스윕+FDD 시크음, 산 카드의 첫 귀환 | G1: 4/5가 "산 카드는 섞인 뒤 나온다" 설명 |
| 폭발적 상환 — 준비한 엔진이 터짐 | LAST LIVE 반전 + 16/32/48 캐리어 버스트 | G2: 4/5가 반전을, 3/5가 "접수 느낌"을 설명 |
| 적응 — 이번 왕국에서 다른 답 만들기 | 킹덤 8중5 + 지침 1종 | G2: 두 번째 런에서 의도적 전략 변경 3/5 |
