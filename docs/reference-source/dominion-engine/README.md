# Dominion Engine

A Python implementation of the card game *Dominion* with a focus on AI strategy development and simulation.

## Goals

This project aims to provide a clean, extensible engine for Dominion that can:

* Simulate complete games between AI agents
* Benchmark and compare different strategies
* Serve as a foundation for more advanced techniques such as Monte Carlo search and reinforcement learning
* Eventually support the full set of official Dominion expansions

The emphasis is on correctness, reproducibility, and experimentation rather than building a graphical game client.

## Current Features

* Complete game engine for a subset of Dominion
* Turn phases (Action, Treasure, Buy, Cleanup)
* Supply piles and game end conditions
* Agents choose only from legal moves generated by the engine
* Simulation environment for automated matches

### Implemented Cards

* Copper
* Silver
* Gold
* Estate
* Province
* Smithy
* Village

### Implemented Agents

* Random Agent
* Big Money
* Big Money + Smithy

## Running a Simulation

```bash
uv run python -m dominion.run
```
