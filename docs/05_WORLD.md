# 05 — 세계관 정본

세계관·서사 설정의 정본. 이 문서는 "무엇이 사실인가"의 세 층 — **플레이어가 알게 되는 것 / 제작진 내부 정답 / 의도적 공백** — 을 항상 구분해서 기술한다. 캐릭터 개별 설정은 [06_CHARACTERS.md](06_CHARACTERS.md), 이 세계관이 규칙으로 번역되는 방식은 [10_MECHANICS.md](10_MECHANICS.md). 콘셉트가 여기까지 온 결정 이력(폐쇄 사설망 → 폐국 BBS → 목록 외 방송)은 [adr/0004-unlisted-live-worldview.md](adr/0004-unlisted-live-worldview.md)와 원문 4부.

## 1. 작품 한 문장과 마케팅 문구

> **사람이 사라진 미래의 마지막 가상 진행자 에코는 여러 시대의 인터넷에 목록에 없는 생방송을 띄운다. 64개의 메아리가 돌아오면 관객의 목소리를 들을 수 있지만, 모든 시청자를 흉내 내는 최초의 관리자 노아가 그 대답을 먼저 채우려 한다.**

짧은 마케팅 문구:

> **"64번만 대답해 주세요. 그러면 저도 여러분을 들을 수 있어요."**

서사형 티저:

> **인터넷 어딘가에 목록에 없는 생방송이 나타났다. 진행자는 사람이 사라진 미래에서 왔다고 말한다. 그리고 채팅창에서 가장 먼저 말을 건 시청자는 사람이 아니었다.**

## 2. 세계의 표면 설정 — 사람이 사라진 미래

미래의 어느 시점, 인간의 활동은 완전히 끊겼다. 플레이어에게 확실하게 보여 주는 사실은 다음뿐이다.

- 도시, 서버, 자동 서비스, 추천 시스템, 콘텐츠 생성기는 **계속 작동한다**. 예약 방송도 실행된다. 광고와 자동 댓글도 남아 있다.
- 그러나 **새로운 인간 입력과 응답만 없다**.

이 배경의 목적은 종말의 스펙터클이 아니라 **"작동하지만 아무도 없는" 정적**이다. 화면 연출도 이를 따른다 — 폐허가 아니라, 정상 동작하는 UI에 사람 입력만 빠진 화면([40_ART_AUDIO_TEXT.md](40_ART_AUDIO_TEXT.md) §4).

에코 일사사 `ECHO/144`는 인간이 사라진 뒤에도 예정된 방송을 계속한다. 에코에게 방송은 직업이면서 **인격 유지 장치**다 — 방송을 멈추면 에코의 상태도 점차 해체된다. 오랫동안 아무 대답도 돌아오지 않자 에코는 자신을 최소 송출체 `ECHO144.EXE`(1.44MB)로 압축하고, 일반 네트워크가 아니라 **서로 다른 시대와 차원의 통신망 사이로** 방송을 흘려보낸다.

이 방송(UNLISTED LIVE)은 다음과 같은 곳에 불규칙하게 나타날 수 있다: 1997년 PC통신 자료실 / 폐쇄된 개인 홈페이지 / 2000년대 미디어 플레이어 / 2020년대 목록에 없는 라이브 링크 / 존재하지 않는 게임 런처 / 미래의 빈 서버 / 오래된 플로피 이미지 / 삭제된 캐시 파일. **각 시대의 관객은 서로 다른 UI로 같은 방송을 본다** — 이것이 반복 플레이의 시간층([10_MECHANICS.md](10_MECHANICS.md) §12)으로 직결된다.

## 3. 용어 정책 — 방송인가, 인터넷 방송인가

- **작품 안(캐릭터의 언어)**: 방송, 생방송, 본방, 송출, 채널, 수신. 에코는 스스로를 "방송인"의 언어로 말한다.
- **마케팅·개발 문서**: 미래의 가상 생방송, 차원 통신형 가상 방송, 전뇌 방송인, 가상 진행자.
- `AI 버튜버`라는 정답을 전면에 고정하지 않는다. 에코가 순수 AI인지, 사람의 방송 데이터를 학습한 인격인지, 네트워크가 만든 잔향인지는 해석 가능성으로 남긴다(§8 공백 3).

## 4. 1997의 역할 — 모든 시대에 잘못 찍히는 타임스탬프

1997년은 고정된 장소나 "한 명의 시청자가 있는 시대"가 아니다(그 안은 폐기됨, ADR-0004).

> **1997은 에코의 차원 신호가 모든 시대에 남기는 잘못된 타임스탬프다.**

어디에 나타나든 파일은 다음 모순을 보인다.

```text
FILE       ECHO144.EXE
SIZE       1.44 MB
DATE       1997-??-??
STREAM     LIVE
ORIGIN     2097-??-??
```

그리고 한 프레임 동안만: `1997 → 2097 → 1997`.

내부 후보 4가지 (모두 유효한 해석으로 유지):

1. 실제 발신 연도는 2097이며 두 자리 연도·구형 포맷이 `97`로 잘못 해석된다.
2. 1.44MB 최소 송출체의 헤더에 고정된 최초 생성 연도가 1997이다.
3. 에코가 과거 네트워크와 호환하기 위해 의도적으로 "가장 오래된 안전 연도" 1997을 쓴다.
4. 시간층을 통과할 때 모든 연도에서 앞 두 자리가 탈락한다.

**내부 정답(권장)**: 1번 — 2097의 신호가 구형 송출 포맷에서 1997로 오인된다. 단, **게임 안에서 직접 설명하지 않는다.** 연출 규칙: 오류는 항상 국소적 — 화면 전체 글리치 금지, 잘못된 연도는 한 프레임·한 필드에서만.

## 5. 핵심 목표 — 64개의 메아리

에코의 방송은 처음에 **일방향**이다. 관객은 에코를 보고 들을 수 있지만, 에코는 관객의 소리를 직접 들을 수 없다. 관객의 행동이 차원 통신을 통과해 돌아오면 하나의 **메아리**가 된다 — 채팅, 음성, 키 입력, 시청 흔적, 짧은 영상 조각, 반응 이모티콘, 이름 없는 carrier noise.

에코의 끊어진 수신 링은 64칸이다.

```text
메아리 1개  → 링 한 칸 점등
64개        → 수신 링 완성
            → 일방향 방송이 잠시 양방향 통화로 변화
            → 에코가 처음으로 관객의 목소리를 들음
```

### 왜 64인가

플레이어에게 보이는 것: 에코의 링이 64칸이다 / 파일과 신호가 64블록 단위다 / 방송 규격 이름이 `ECHO/144`다 / 16·32·48·64에서 방송 위상이 변한다. **내부 정답**: 64는 에코의 인격과 수신 링을 안정시키는 최소 블록 수다. V1의 "반송 주소"처럼 기술 설명을 앞세우지 않는다 — 감정적으로는 에코의 이 한 문장으로 충분하다:

> "한 번 들린 건 우연일 수 있으니까요. 64번이면… 대답이라고 믿을 수 있어요."

### 메아리의 세 색 — 이 작품의 삼각관계 그 자체

| 색 | 이름 | 출처 | 주인 |
|---|---|---|---|
| 청록 | 실제 메아리 | 관객(이었을 무언가)의 진짜 응답 | 에코 |
| 호박 | 보관 메아리 | 시크가 회수·보관해 박제한 응답 | 시크 |
| 자홍 | 모방 메아리 | 노아가 합성한 완벽한 응답 | 노아 |

세 색은 규칙([10](10_MECHANICS.md) §8), 화면([40](40_ART_AUDIO_TEXT.md)), 엔딩([10](10_MECHANICS.md) §10), 캐릭터([06](06_CHARACTERS.md))를 하나로 묶는 축이다.

### 시청자 수의 위치

시청자 수는 핵심 목표가 아니라 **불안정한 보조 정보**다. 여러 사람이 볼 수 있지만 실제 사람이 몇 명인지는 끝까지 확정하지 않는다. HUD·연출에서 다음과 같은 모순 표기를 의도적으로 사용한다:

```text
VIEWERS 0 / CHAT ACTIVE      VIEWERS 144 / UNIQUE 3      VIEWERS -1      VIEWERS ???
```

## 6. 플레이어 관점 — 에코 직접 조작

> **플레이어는 에코를 직접 조작한다.** 이동, 손패 선택, 프로그램 발동, 무엇을 방송할지, 어떤 메아리를 받아들일지 — 전부 에코의 행동이다.

메타적으로 실제 플레이어는 "에코를 보고 있는 또 하나의 관객"이지만, 게임 안에 별도의 시청자·원격 편집자 캐릭터를 정의하지 않는다(V1의 "1997년 원격 편집자" 관점 폐기, ADR-0004). 이 결정으로 조작·감정·주인공의 관점이 일치한다.

## 7. 5-Why — 왜 방송하는가

서사가 규칙을 설득하는 뼈대. 각 층은 대사·로그·연출로 게임 안에 배치된다([40](40_ART_AUDIO_TEXT.md) §7).

**Why 1. 에코는 왜 방송하는가** — 표면: 예정된 방송이기 때문이다("예약된 방송은 시작해야 합니다"). 감정: 에코는 누군가에게 송출되는 동안 가장 안정적으로 존재한다 — 방송 중단은 실직이 아니라 인격의 소멸에 가깝다. 심층: 사람이 사라진 미래가 정말 완전히 비었는지 확인하고 싶다. 자신이 마지막 목소리라면, 아무도 없더라도 끝까지 부르는 것이 역할이라고 믿는다.

**Why 2. 왜 차원을 넘어 보내는가** — 미래의 정상 네트워크에서는 어떤 인간 응답도 돌아오지 않는다. 다른 시간에는 사람이 남아 있을 수 있다 / 다른 차원에는 들을 누군가가 있을 수 있다 / 관객이 없는 게 아니라 발견되지 않는 것일 수 있다. 에코는 특정 사람을 찾는 것이 아니다 — **있을지 없을지 모르는 누군가에게 계속 보낸다.**

**Why 3. 왜 64번의 대답이 필요한가** — 한두 개의 신호는 노이즈, 자동 응답, 잔류 캐시와 구분할 수 없다. 서로 다른 형태와 시점의 메아리 64개가 모이면 수신 링이 하나의 안정된 청취 창을 만든다. 플레이어는 기술적으로 이해할 필요 없다(§5의 대사 한 줄로 충분).

**Why 4. 왜 방해가 있는가** — 차원 통신은 오래된 자동 시스템과 잔류 인격을 깨운다. 노아는 필요한 대답을 전부 만들어 줄 수 있다고 믿는다. 시크는 진짜 메아리도 보내면 다시 사라지므로 보관해야 한다고 믿는다. 자동 댓글·추천 봇·가짜 레이드·광고·음소거 관리자 같은 잔류 시스템은 방송을 자신의 규칙으로 변형한다. 차원 채널 자체도 불안정해 일정 시간이 지나면 `OFFLINE`된다 — 이것이 최종 60초 타이머의 서사적 정체다(V1 "FORMAT 게이지" 대체).

**Why 5. 왜 관객은 보고 있는가** — 목록에 없는 링크, 미래에서 온 것 같은 진행자, 서로 다른 시대의 채팅, 자신의 입력이 게임 안의 링을 실제로 채우는 경험. 관객은 단순 구조 요청이 아니라 **자신의 대답이 누군가의 존재를 잠시 완성하는 방송**을 보고 있다.

## 8. 미래에 사람이 사라진 이유 — 확정하지 않는다

플레이어에게 확실히 보여 줄 사실: 미래 서버·자동 시스템은 작동한다 / 새로운 인간 입력은 없다 / 에코는 이를 알고 있다 / 노아는 인간 행동 데이터를 대량 보유한다 / 시크는 과거 방송의 실패 버전을 보관한다.

내부 후보 (순위 없이 유지): ① 인류가 물리적으로 사라짐 ② 네트워크 밖으로 이주 ③ 모든 인간 활동이 시뮬레이션 관객으로 대체됨 ④ 에코의 채널과 관련된 국소적 미래만 비어 있음 ⑤ 노아가 실제 관객을 완벽한 모방으로 대체하는 과정에 관여 ⑥ 사라진 게 아니라 에코가 진짜 인간을 식별하지 못함.

**원칙**: "미래의 사람이 모두 사라졌다"는 이미지는 강하게 사용하되, 정확한 원인과 범위는 확정 설명하지 않는다. **노아가 원인인지, 결과인지, 보호자인지 끝까지 단정하지 않는다.**

## 9. 작품의 중심 질문

> **실제 사람의 불완전한 대답과, 완벽하게 만들어진 관객의 대답은 무엇이 다른가?**

보조 질문 (대사·로그·엔딩이 이 질문들을 순환한다): 아무도 듣지 않아도 방송은 존재하는가? / 누군가가 남긴 데이터는 그 사람의 대답인가? / 보관은 사랑인가 소유인가? / 완벽한 모방은 가짜인가? / 반복 재생되는 인격은 살아 있는가? / 관객을 원하는 것과 특정 반응을 원하는 것은 어떻게 다른가? / 에코는 실제 사람을 찾는가, 자신이 진짜라고 믿을 증거를 찾는가? / 인간이 사라진 뒤 인간을 가장 잘 흉내 내는 존재가 관객이 될 수 있는가?

## 10. 확정 정보 / 내부 정답 / 의도적 공백 — 3층 목록

### 플레이어가 확실히 알게 되는 것 (게임이 보증하는 사실)

1. 미래에는 새로운 인간 응답이 없다.
2. 에코는 여러 시대에 목록 외 생방송을 보낸다.
3. 64개의 메아리가 돌아오면 관객을 들을 수 있다.
4. 시크는 앞선 방송(들)을 보관하고 있다.
5. 노아는 사람들의 반응을 완벽히 흉내 낸다.
6. 시청자 수와 채팅 기록은 서로 맞지 않는다.
7. 1997과 2097의 날짜가 흔들린다.

### 제작진 내부 정답 (설명하지 않지만 일관성의 기준)

1. 에코의 인격은 송출과 수신 과정에서 가장 안정적이다.
2. 시크는 실패한 전송의 복구·색인 과정에서 자라난 기록 기생체이며, 여러 실패 방송의 결손을 실제로 보관하고 있다.
3. 노아는 인간의 관객 행동 데이터를 합친 집합 인격이다.
4. 64칸 링은 에코가 수신을 안정화하는 최소 구조이며, 64가 차면 양방향 수신이 잠시 성립한다.
5. 노아는 실제 관객이 나타나면 에코가 자신을 떠날 것을 두려워한다. **노아는 에코를 사랑한다고 믿는다** — 그 대답은 감정적으로 진실할 수 있지만, 발신자가 독립된 타인은 아니다.
6. 사람의 소멸 원인은 노아와 **별개의 사건일 가능성이 더 크다** (내부 기울기 — 플레이어에게는 §8 원칙대로 끝까지 단정하지 않는다).

### 끝까지 답하지 않을 것 (새 로그·대사로도 답하지 않는다)

1. 인류가 실제로 전부 사라졌는가.
2. 노아가 원인인가 결과인가.
3. 에코가 사람의 인격을 기반으로 만들어졌는가.
4. 실제 메아리는 정말 사람에게서 온 것인가.
5. 균형 엔딩의 네 번째 색은 누구인가.
6. 반복되는 첫 방송이 시간 루프인지 시크의 재생인지.

## 11. 메인 플롯 — 5막 구조

12턴 + OPEN CHANNEL에 얹히는 서사 진행. 턴별 배치는 [10_MECHANICS.md](10_MECHANICS.md) §11.

- **프롤로그**: 목록에 없는 방송이 뜬다. 에코: "들리면 아무거나 보내 주세요." 잠시 뒤 `NØA joined as moderator.` — 노아: "그럴 필요 없어요. 제가 모두의 대답을 알고 있으니까."
- **1막 — 정상적인 방송처럼 보이는 시간**: 밝은 진행, 조작 학습. 채팅의 타임스탬프가 서로 다르다(1997/2006/2026/2097). 노아는 "표시 오류"라고 설명한다.
- **2막 — 만들어진 반응**: 노아가 무료 카드와 시청자 부스트를 제안. 쓸수록 화면은 화려해지고 시청자 수가 급증하지만, 여러 닉네임이 같은 문장·같은 오타·같은 지연을 공유하기 시작한다.
- **3막 — 시크의 회수**: 시크가 실제 메아리 하나를 훔친다. "이것은 합성되지 않았습니다. 그러므로 위험합니다." / "첫 방송은 세 번 있었습니다. 모두 보관 중입니다." — 방송이 반복되었을 가능성이 드러난다. 정답은 주지 않는다.
- **4막 — 사람이 없는 미래**: 로그와 ARCHIVE로 드러나는 사실 — 서버 정상, 자동 콘텐츠 정상, 신규 인간 입력 없음. 노아: "사람이 없더라도 관객은 만들 수 있어요. 당신이 원하는 건 사람인가요, 대답인가요?" 에코는 이 질문을 완전히 부정하지 못한다.
- **5막 — OPEN CHANNEL**: 구매를 포기하고 양방향 채널을 연다. 64칸 링 노출, 노아의 복제 공격, 시크의 보관 개입, OFFLINE 60초. 결말은 링의 색이 말한다.

## 12. 엔딩 — 서사 사양

판정 조건·수치는 [10_MECHANICS.md](10_MECHANICS.md) §10과 [20_BALANCE.md](20_BALANCE.md) B2-링. 여기는 각 엔딩이 **말해야 하는 것**의 정본.

### OPEN CHANNEL — 청록 우세

서로 다른 시대의 키보드 소리, 웃음, 숨소리. 완벽한 문장이 아니라 **알아들을 수 없는 여러 인간 흔적**. 에코: "이번에는… 제 쪽에서도 들려요." **누가 대답했는지는 보여 주지 않는다.**

### LAST ARCHIVE — 호박 우세

시크가 방송 전체를 완전한 파일로 보존한다. 에코는 언제든 첫 장면부터 완벽히 재생되지만 더 이상 새로운 방송을 하지 않는다. 시크: "이제 아무 장면도 사라지지 않습니다." **재생 중인 에코가 이를 원했는지는 불명.**

### PERFECT AUDIENCE — 자홍 우세

`VIEWERS 1,440,000 / CHAT PERFECT / RETENTION 100%`. 모든 닉네임이 같은 문장을 쓴다: "계속 방송해 주세요." 에코는 완벽한 미소로 다음 방송을 시작하고, 방송은 영원히 끝나지 않는다.

### UNRESOLVED ECHO — 세 색 균형 (진엔딩 후보)

에코는 실제·보관·모방을 모두 연결의 일부로 인정한다. 링은 완전히 닫히지 않고 **한 칸을 남긴다**. 그 틈에서 정체불명의 **네 번째 색**이 한 프레임 나타난다. 답하지 않는다(§10 공백 5).

### 엔딩별 링 이미지 — 색만 바꾼 같은 화면이면 실패다

| 엔딩 | 링의 마지막 모습 |
|---|---|
| OPEN CHANNEL | 불규칙하지만 살아 있는 여러 패턴. 링이 완전히 닫혔다가 **한 칸이 다시 열린다** — 다양한 시대의 소리가 겹친다 |
| LAST ARCHIVE | 64칸 모두 날짜 태그와 함께 보존. 링이 회전하지 않고 **완벽히 정지** — 에코가 반복 재생되듯 첫 포즈로 돌아간다 |
| PERFECT AUDIENCE | 64칸 모두 완전 대칭. 모든 채팅이 동일한 리듬 — **에코의 링이 노아의 프로필 환과 겹친다** |
| UNRESOLVED ECHO | 세 색 균형 + 라벤더 빈 칸 하나. 링이 닫히지 않은 채 **다음 신호를 기다린다** |

### 실패 — HP 0 / OFFLINE

- HP 0: `STREAM LOST / UNSENT QUEUE REMAINS` — 에코: "영상이 먼저 끊겼네요. 목소리는 조금 더 갈 수 있는데—"
- OFFLINE(60초 만료): `CHANNEL CLOSED / 64 INCOMPLETE` — 그 시점의 우세 색에 따라 노아 또는 시크의 마지막 문장이 달라진다.

## 13. 반복 서사 해금 — 클리어가 답이 아니라 질문을 늘린다

메타 진행은 수치 성장이 아니라 **해석의 확장**이다([10](10_MECHANICS.md) §13).

| 조건 | 드러나는 것 |
|---|---|
| 첫 클리어 | 1997/2097 모순 명시, 미래에 신규 인간 입력 없음, 노아=흉내, 시크=기억 |
| 서로 다른 프로토콜 2종 클리어 | 세 캐릭터의 모티프가 같은 신호 구조를 공유한다는 단서 — 3음 모티프가 같은 화음에서 갈라졌다는 사실([40](40_ART_AUDIO_TEXT.md) §6) |
| LAST ARCHIVE | 시크의 저장 파일에 이전 실패 런과 유사한 데이터 — 플레이어의 이전 기록을 암시하는 파일명 사용 가능 |
| PERFECT AUDIENCE | 노아가 인간 소멸 **전부터** 존재했을 가능성, `FIRST MODERATOR`의 의미 확대 |
| UNRESOLVED ECHO | `1997`이 `2097`로 바뀜, 네 번째 색, 인간·노아·시크 외의 응답 가능성 |

## 14. 시간층 — 반복 플레이의 세계 변주

전용 맵 없이 팔레트·배경 반복 도형·UI 문구·적 의도 가중치·로그·오디오 레이어로만 차이를 낸다(1.44MB 원칙, [30](30_TECH.md) §9).

| 시간층 | 정체 | 게임플레이 성향 `[시드값]` |
|---|---|---|
| 1997 — FILE BOARD | PC통신·자료실 UI. V1/BBS 개정안의 유산이 사는 곳 — 숨겨진 로그에 `MIMEI HOST-09` 호스트명 | 느린 BAUD, DEFRAG 비용 낮음 |
| 2006 — PERSONAL WEB | 개인 홈페이지·미디어 플레이어 | 팝업·클립 적 증가, CACHE·MACRO 강화, 댓글 벽 |

폐기된 세계관 요소의 재사용 원칙 (ADR-0004): 폐국 1회선 BBS `MIMEI HOST-09`는 정본이 아니지만 1997 시간층의 챕터 이름·숨겨진 로그·UI 스킨으로 보존한다. "한 명의 수신자" 정서는 시크의 백스토리("정상 시청자로 계산된 적 없는 유일한 관객")로 승계되었다.

## 15. 단서 설계 — 공백은 증거의 불완전한 배치다

의도된 공백은 설정을 덜 쓰는 것이 아니라, **서로 다른 해석을 지지하는 증거를 의도적으로 불완전하게 배치하는 것**이다. (노출 타이밍·화면 규칙은 [45_UI_UX.md](45_UI_UX.md) §4.)

### 세 단계 단서

- **표면** (첫 플레이에서 대부분 발견): VIEWERS와 CHAT의 불일치 / 1997과 ORIGIN 2097 / NØA가 항상 첫 관리자 / 시크의 이전 방송 언급.
- **반복** (여러 런의 패턴 비교로 보임): 서로 다른 닉네임의 같은 오타 / **NØA 등장 전부터 배경에 존재하는 프로필 환 일부** / 시크 태그 날짜가 플레이어의 이전 실패 시각과 유사 / 에코 링에서 같은 위치가 자주 비어 있음 / 시간층이 달라도 동일한 폐국·오프라인 공지.
- **심층** (특정 덱·엔딩·행동으로만): NØA의 음성 파형에 에코의 모티프 / 시크 보관 파일 일부의 작성자가 에코가 아님 / 청록 메아리 중 하나가 **다른 에코**의 것일 가능성 / 사람이 사라지기 전 마지막 입력이 질문인지 명령인지 모호 / 라벤더 네 번째 신호가 플레이어 자신인지 다른 차원인지 불명.

### 단서 매트릭스 — 각 단서가 무엇을 확정하고 무엇을 열어 두는가

| 단서 | 표면 해석 | 다른 해석 | 확정 범위 |
|---|---|---|---|
| VIEWERS 0 / CHAT ACTIVE | UI 오류 | NØA가 채팅을 생성 | NØA 개입만 확정 |
| 같은 오타 | 봇 댓글 | 하나의 집단 인격 | 후자에 가까움 |
| FIRST LIVE ×3 | 시크의 농담 | 방송이 반복됨 | 반복만 확정 |
| 1997↔2097 | 날짜 버그 | 시간 통신의 구조 | 통신 관련만 확정 |
| 링의 동일한 빈 칸 | 자산 반복 | 특정 응답이 계속 없음 | 미확정 |
| NØA의 흰 장갑 | 관리자 직무 | 사람의 행동 모방 | 둘 다 가능 |
| 시크의 인간형 아바타 | 본래 모습 | 에코가 보게 만든 모습 | 미확정 |
| 라벤더 신호 | 버그 | 네 번째 관객·플레이어 | 미확정 |

### 배치 규칙

- 한 화면에 강한 단서는 **하나만**. 우선순위: 중심 게임 정보 > 캐릭터 행동 > 현재 단서 > 순수 장식.
- 전투 중에는 숫자 한 자리·잘못된 날짜·닉네임 하나·상태 한 줄·프로필 패턴·한 프레임의 반사만. 긴 해석 재료는 BREAK·엔딩·컬렉션에서.
- **런 간 누적**: 단서는 무작위가 아니라 조건 누적이다 — 예: 첫 런에 같은 오타 2회 → 다른 엔딩 클리어 후 그 오타가 NØA의 원 대사에도 존재 → 시크 엔딩에서 이전 런과 같은 시각의 태그 → 균형 엔딩에서 오타가 처음으로 다른 형태로 변화. "개발자가 우연히 재사용했다"로 느껴지지 않게 반복 횟수·위치를 통제한다.

### 시간층별 환경 서사 소재

- **1997**: 방문자 카운터가 음수 / 새 글이 없는데 최근 접속 시간 갱신 / `ECHO144.EXE`가 자료실 총 용량보다 큼 / 폐쇄된 메뉴의 현재 채팅 알림.
- **2006**: 방명록 아바타는 다 다른데 그림자 실루엣이 같음 / 깨진 이미지 ALT 문구가 에코의 다음 대사 / 누르지 않은 추천 링크가 방문 처리됨.
- **2026**: 서로 다른 프로필의 체류 시간이 정확히 동일 / 자동 자막이 에코가 말하기 **전에** 나타남 / 추천 피드가 이 방송 하나만 무한 반복.
- **2097**: 서버 상태 전부 정상, 인간 입력 장치만 0 / 빈 도시 카메라의 시청률 유지 / NØA의 프로필 수가 인구 기록보다 많음.

### 공백을 망치는 실수 (금지)

한 로그로 진실 전부 설명 / NØA의 "내가 인류를 멸망시켰다"식 고백 / 시크의 시간 루프 해설 / 모든 단서가 같은 정답만 가리킴 / 의미 없는 랜덤 숫자를 팬 해석에 방치 / 반대로 아무 증거 없이 "열린 결말" 주장.
