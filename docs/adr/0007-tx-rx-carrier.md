# ADR-0007 — CARRIER의 TX/RX 양면 사용

- 상태: 채택 (2026-07-16), P0 슬라이스에서 검증 / 원문: [../archive/ECHO144_1_44MB_REFERENCE_ANALYSIS.md](../archive/ECHO144_1_44MB_REFERENCE_ANALYSIS.md) §4

## 결정

CARRIER(모뎀 카드)는 매 턴 EDIT에서 **TX(송신 = 이번 ON AIR 자동 공격, 구매력 0) 또는 RX(수신 = 공격 없음, BREAK에서 BAUD 제공)** 중 하나로 지정된다. Dominion의 Treasure를 "지금 싸울 것인가, 다음 카드를 살 것인가"의 실시간 선택으로 번안한 것이다.

## 맥락

기존 설계(V1·V2 초안 공통)에서 모뎀은 공격과 구매력을 **동시에** 제공했다. 이해는 쉽지만 — 모뎀이 현재 생존과 미래 경제를 모두 해결해 다른 카드군보다 구조적으로 유리하고, 구매력이 자동으로 생기며, 손패마다 결정이 부족했다.

TX/RX 하나로 동시에 해결되는 것: Treasure·공격 역할 혼합 / 현재 생존 vs 장기 성장의 긴장 / 손패 의사결정 밀도 / 모뎀 다수 전략의 개성 / PROGRAM·ARCHIVE의 덱 희석 체감 / "대역을 어디에 쓰는가"라는 방송 세계관.

## 안전장치·검증

- 입문: 첫 3턴 위험도 기반 추천 표시 + 접근성 자동 배정 옵션. 기본 규칙에서는 플레이어가 결정.
- 수용 기준([20](../20_BALANCE.md) B2-지표): 구절의 ≥30%에서 배분이 갈리고, 전부 TX·전부 RX 어느 쪽도 상시 정답이 아니며, 30초 내 UI 이해.
- OPEN CHANNEL에서는 구매가 없으므로 전 CARRIER 자동 TX — RX의 소멸 자체가 "마지막 방송" 연출.
- 열린 변수: BREAK 주기(매 턴 vs 2구절+RX 누적)는 A/B ([10](../10_MECHANICS.md) §16-17).

## 기각된 대안

- 현행 유지(공격+구매 동시): 위 문제 존속.
- 별도 "경제 전용 카드" 신설: 카드 종류만 늘고 손패 내 선택은 늘지 않음.
