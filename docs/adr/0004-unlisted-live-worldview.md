# ADR-0004 — 폐쇄망·BBS를 폐기하고 "목록 외 방송" 세계관으로

- 상태: 채택 (2026-07-16) / 원문 4부, 부록 D

## 결정

세계관을 **"사람이 사라진 미래의 에코가 여러 시대의 인터넷에 띄우는 목록 외 생방송(UNLISTED LIVE)"**으로 확정한다. 플레이어는 에코를 직접 조작한다. 목표는 "반송 주소"가 아니라 **64개의 메아리**다.

## 결정 이력 (3단계)

1. **폐쇄 사설망 / NODE 09** (V1): 분위기는 강했으나 — 폐쇄여야 하는 게임적 이유 부족, 즉시 이해되는 고유명사 아님, 플레이어 관점(시청자? 에코? 편집자?) 흔들림, "반송 주소" 훅 약함.
2. **폐국 1회선 BBS / MIMEI HOST-09**: 한 명=만석 규칙, 자료실=카드 구매 결합, PC통신 미학. 그러나 — 작품 스케일을 한 호스트·한 명의 수신자에 가둠, 플레이어를 원격 편집자로 만들어 주인공성과 분리, "미래의 마지막 방송"이라는 보편성과 충돌.
3. **여러 시대의 UNLISTED LIVE** (정본): 다양한 시대·관객·인터페이스 수용, 사람이 사라진 미래와 정합, 반복 플레이의 시간층과 자연 결합, 에코 직접 조작으로 조작·감정·관점 일치.

## 보존 (폐기가 아니라 축소 재배치)

- `MIMEI HOST-09`·PC통신 미학 → **1997 시간층**의 챕터·숨겨진 로그·UI 스킨.
- "한 명의 수신자" 정서 → 시크의 백스토리(정상 시청자로 계산된 적 없는 유일한 관객).
- `NO CARRIER`·플로피·1.44MB 기호 → 전 시간층 공통 브랜드.

## 결과

- 1997은 장소가 아니라 **모든 시대에 잘못 찍히는 타임스탬프**로 재정의([05](../05_WORLD.md) §4). 내부 정답(2097 오인)은 게임에서 설명하지 않는다.
- "한 명의 시청자·만석" 계열 V1 대사는 폐기, 시청자 수는 모순 표기(`VIEWERS ???`)로 대체.
