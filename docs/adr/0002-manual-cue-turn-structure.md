# ADR-0002 — 자동 실행을 폐기하고 EDIT+CUE 수동 편성으로

- 상태: 채택 (2026-07-16), GV2 go/no-go 게이트로 최종 확정 ([50](../50_PRODUCTION.md) §4) / 원문 7부·부록 C

## 결정

V1의 "5장 손패 전부 자동 실행"을 폐기하고, 턴 구조 `EDIT(정지 편성) → ON AIR(8초 실시간·수동 발동) → BREAK(구매) → CLEANUP(셔플)`과 액션 경제 `CUE`(기본 1, MULTI로 확장)를 채택한다.

## 맥락

V1 자체 평가: 손패 의사결정 3/10, 액션 경제 2/10, 엔진 구축 체감 4/10. 플레이어 체감이 "자동으로 공격하는 캐릭터를 움직이고, 가끔 카드 하나를 산다"로 수렴할 위험. 도미니언의 핵심(덱 순환 효율, terminal collision, Big Money 기준선, 승점 오염, 종료 조절) 중 **terminal collision과 손패 선택이 통째로 빠져 있었다.**

## 결정 이력 (3단계)

1. **최초 현행안** — 전부 자동: 접근 쉬움, 흐름 안 끊김. 그러나 선택 부재.
2. **중간 하이브리드** — 미리보기 + 슬로모 0.6~0.8초 + PROGRAM 1장만 CUE: 흐름 보존, 한 손패 한 선택. 그러나 "모든 카드가 흘러가는" 구조가 도미니언 감각을 복원하지 못함.
3. **현재 정본** — 명시적 EDIT + 수동 발동: 직접 전략 감각, 적 의도와 손패 대응 연결, 수동 위치·타이밍의 가치. 입문은 정지 편성·자동 추천·자동 발동으로 보호.

## 리스크와 안전장치

- EDIT가 템포를 끊을 위험 → 완전 정지는 기본이되 무입력 자동 추천, 숙련 슬로모 옵션. GV2 문항으로 측정, 코어 가설 기각 시 V1 복귀([50](../50_PRODUCTION.md) §1).
- 수동 발동과 이동의 조작 충돌 → Space 큐 방식(조준 불필요), 발동 슬로모 검토. 버튼 추가 금지.
