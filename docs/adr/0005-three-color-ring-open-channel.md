# ADR-0005 — 단일 SIGNAL을 3색 64칸 링 + OPEN CHANNEL로

- 상태: 채택 (2026-07-16) / 원문 9~10부

## 결정

- V1의 단일 `SIGNAL 0→64` 게이지를 **청록(실제)·호박(보관)·자홍(모방)의 3색 64칸 링**으로 대체한다. 색 구성이 승리 경로이자 관계 게이지이자 엔딩 분기다.
- V1의 `GO LIVE`를 **OPEN CHANNEL**로 개명·재정의한다 — 게임은 처음부터 생방송이므로, 최종 단계는 "방송 시작"이 아니라 **양방향 개방**이다.
- V1의 `FORMAT 게이지 100%`는 **차원 채널의 OFFLINE 60초 타이머**(환경)로 대체한다(ADR-0003 연동).

## 맥락

단일 게이지는 "얼마나 모았나"만 말한다. 3색 링은 같은 UI 픽셀로 **무엇을 대답으로 받아들였나**(덱 선택 → 색 → 엔딩)까지 말한다 — 세계관의 중심 질문(실제 vs 보관 vs 모방)이 승리 조건 그 자체가 된다. 14점 후보: "64칸 링의 색이 덱, 관계, 승리, 엔딩을 동시에 표현한다."

## 본 개정에서 구체화한 것 (원문이 연 질문의 시드 답)

- 링은 1턴부터 상시 노출, 일반 방송 수급 상한은 링의 1/4 — 엔딩 예측 가능성 확보 (F7).
- ARCHIVE 반전은 효과+비용(CUE 0) 이중 반전 — 부담↔무료의 대칭.
- 메아리 1개 = 채팅 1줄(질감 차이로 3색의 윤리를 비언어 전달).
- 엔딩 판정 우선순위: 균형 → 자홍 → 호박 → 청록([20](../20_BALANCE.md) B2-링).

## 유지 (V1에서 검증된 뼈대)

64 목표 / 임계(16·32·48) 위상 변화는 수치 이득 없음 / 동일 틱 64 우선 / 검산 기준점 30·54 / 조기 종결 선택권.
