# ADR-0008 — 아트 파이프라인 전환: 자산 재설계·Aseprite 원본·.px 강등

- 상태: 채택 (2026-07-16) / 원문: [../archive/ECHO144_V2_ART_VISUAL_REFACTOR.md](../archive/ECHO144_V2_ART_VISUAL_REFACTOR.md) §1·§2·§23

## 결정

1. **V1 자산은 부분 수정·재라벨하지 않고, 브랜드 DNA만 계승해 V2 기준으로 재설계한다.** V1 자산·규격은 `assets/archive_v1/`·[archive/v1-last-live/](../archive/v1-last-live/)에 동결하고 V2 코드가 직접 참조하지 않는다. (본 결정은 앞선 개정의 "승계·재라벨 우선" 방침을 **대체**한다.)
2. **`.px` 텍스트 그리드를 원본에서 강등한다** — 검수용 덤프·diff·1bpp 긴급 수정·테스트 fixture로만. 원본은 레이어·프레임·태그·피벗이 보존되는 **Aseprite(.aseprite)** 등 스프라이트 편집 파일.
3. 규격 변경: 에코 24×24 4bpp(16×16 대비 A/B 게이트), 초상 64×64(48 대비 A/B), 카드 아이콘 16×16, NØA 보스 레이어 합성, 16색 논리 팔레트(+PHANTOM LAVENDER).
4. AI는 착상·구도 탐색까지만 — 최종 자산은 인간 작화 게이트 10단계([41](../41_PIXEL_ART.md) §6).

## 맥락

V1 자산은 `포맷 제로`·`LAST LIVE`·`시청자 1`·자동 발동에 맞춰 만들어졌다. 더 근본적으로 — 세 초상이 같은 얼굴 지오메트리를 공유하고, 차이가 머리색·장식에 몰려 있고, 소품의 물리 연결이 약했다. **원인은 해상도가 아니라 인물별 골격·자세·행동 규칙 없이 생성 규칙에서 출발한 것.** `.px` 원본 공정은 바이트 통제·diff에는 강했지만 "디자인 원본을 생성 규칙에 종속"시켰다 — 절차 생성 픽셀에서도 AI slop(동일 얼굴, 연결 안 되는 기호, 설명 불가 디테일)이 나타난다.

## 근거

- 런타임 제약(1.44MB)과 제작 도구 제약은 별개다 — 도구는 EXE에 들어가지 않는다.
- V2 에코는 CUE·수동 발동·피격 행동을 **행동으로** 보여야 하며 16×16은 그 정보량이 부족하다(24×24, A/B로 확정).
- 파이프라인: `.aseprite → indexed PNG+JSON → assetc.py(팔레트 검증·패킹·린트) → generated/*.inc` — 검수는 contact sheet·스크린샷 회귀로 자동화([41](../41_PIXEL_ART.md) §5).

## 유지되는 것

브랜드 DNA(3색 삼분·끊긴 링·케이블·수직 실루엣·흰 장갑·국소 오류·네거티브 스페이스·인물↔사물 조형 차이) / 320×240·정수 배율 / 빌드 타임 C 배열 임베드(런타임 PNG 로더 없음) / 실루엣 우선·1× 검수·흑백 테스트 등 V1에서 검증된 작화 원칙.
