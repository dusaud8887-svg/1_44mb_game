# 91 — 게임 완성도 심층 감사

기준일: 2026-07-17. 범위는 정본 `00~50`과 현재 V2 P1 코드·`balance.def`·selftest·30시드 SIM의 대조다. 이 문서는 스펙을 바꾸지 않으며, 구현 상태 정본은 [90_STATUS.md](90_STATUS.md)다.

## 1. 결론

현재 빌드는 **처음부터 끝까지 플레이 가능한 V2 P1 수직 슬라이스**다. EDIT→ON AIR→BREAK→OPEN CHANNEL의 핵심 구조, TX/RX, CUE, 덱 순환, ARCHIVE 반전, 3색 64칸 링, 노아의 최다 PROGRAM 복제는 실제 코드 경로로 연결되어 있다.

후속 구현으로 CACHE 대상 선택, FIREWALL 개구부, OFF AIR 3종, BOT/MOD의 지연·NOISE, 시크 거래·OC 케이블, 최근 6구절 TREND, 최종 형태×modifier, 4엔딩·실패 원인, TODAY·저장·DEV 계측까지 실제 경로에 연결했다. 남은 차이는 카드·계약·시간층의 확장 콘텐츠와 사람 검증이다.

따라서 현재 판정은 **P1 기능 완결·자동 게이트 통과 / 코어 재미와 아트 선호는 사람 검증 대기 / 제출 완료 선언은 아직 아님**이다.

## 3. 이번 감사에서 수정한 실제 결함

- 키 자동 반복이 `M` 음소거를 계속 뒤집던 입력 경로를 단발 입력으로 통합했다. 음소거·저자극 설정은 재시작 뒤에도 유지한다.
- `F1` 저자극, `ESC` 일시정지, 결과 화면 오른쪽 키 새 시드, Space 홀드 자동 송출을 실제 동작으로 연결했다.
- HUD에 `구절 N/12`, 첫 3구절 TX/RX 추천, 5구절 이후 노아 학습 대상, 구매 카드의 실제 재드로우 귀환을 표시했다.
- SPON.GIFT를 파괴하면 자홍이 생기던 의미 역전을 수정했다. 접촉 수령은 회복+자홍, 안전 파괴는 SYNC 보상으로 갈린다.
- OPEN CHANNEL 피격의 청록→자홍 전환에 정본의 5초 제한을 적용했다.
- DEFRAG가 덱 최소 5장 아래로 삭제하지 못하게 했고, NOISE 제거 시 기존 실제 흔적만 청록으로 복구하도록 연결했다.

## 4. 재미와 밸런스 판정

### 자동으로 확인된 것

- 7정책×30시드 selftest와 별도 7정책×1,000시드 확장 SIM에서 크래시 0이다.
- 1,000시드에서 6/7 정책이 64에 도달하고 최고 정책은 전체 승리의 40% 미만이어서 구조 기준은 통과한다.
- 시작 덱 OC 기대값 26, VOICE 1장 추가 60의 정본 공식이 회귀 테스트로 고정돼 있다.

### 자동 결과가 드러낸 문제

| 정책 | 승리 | 해석 |
|---|---:|---|
| BIG_BAUD | 158/1000 | 무적 처리량 기준선, 변경 없음 |
| LOOP_ENGINE | 899/1000 | 동일 태그 컴파일 강도로 엔진 투자 회수 성립 |
| ECHO_RUSH | 858/1000 | ARCHIVE 조기 구매의 안정성 유지 |
| CLEAN_SIGNAL | 0/1000 | 방어 가치가 무적 SIM의 승리 지표에는 잡히지 않음 |
| CACHE_COMBO | 892/1000 | NETWORK 강도의 빠른 ARCHIVE 순환으로 고점 회복 |
| PERFECT_SHOW | 780/1000 | 계약 반복 경로가 강함 |
| THREE_WAY | 1000/1000 | 2400 제거+호박 보관과 컴파일 강도를 함께 모델링 |

SIM은 실제 ON AIR 루프와 PROGRAM 효과, 정책별 TX/RX를 실행하지만 의도적으로 무적이다. 컴파일 강도 도입 뒤 복잡 엔진 처리량이 BIG_BAUD를 넘는 자동 기준은 통과했다. 다만 **밸런스 수용 기준 전체 PASS로 부르면 안 된다**. CLEAN_SIGNAL의 생존 가치, THREE_WAY의 실전 위험, Space와 이동을 함께 수행하는 조작 고점은 GV2 사람 실측이 필요하다.

### 사람만 판정할 수 있는 것

- 같은 손패라도 의도에 따라 선택을 바꾸는가.
- Space와 이동이 함께 편한가.
- ARCHIVE 부담→반전이 가장 기억나는 순간인가.
- 노아가 자기 플레이를 배웠다는 사실을 알아차리는가.
- 세 색과 캐릭터 실루엣·카드 효과가 음소거 상태에서도 읽히는가.

이 다섯 항목은 코드나 봇 결과로 PASS 처리하지 않는다. [50_PRODUCTION.md](50_PRODUCTION.md)의 5명 GV2/G3′가 완료 조건이다.

### 1인 실기 스모크 (2026-07-17)

정상 빌드에서 송신/수신을 섞고 MULTI→FIREWALL을 편성한 1~3구절은 체력 5를 유지했다. 이후 구매·편성을 중단하고 이동을 거의 하지 않은 대조 플레이는 7구절에 패배했다. 초반 투자 선택과 방어 편성이 생존 차이로 이어졌으며, 수치 완화 근거는 발견하지 못했다. 다만 결과 직후 반복 이동 입력이 `새 신호`로 해석되는 문제와 문서화된 10초 자동 추천 누락은 재현되어 수정·회귀 테스트했다. 이는 단일 조작 스모크이므로 GV2 사람 재미 판정을 대체하지 않는다.
