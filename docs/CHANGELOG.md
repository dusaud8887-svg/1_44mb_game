# 문서 변경 이력

## 2026-07-19 — 전투 다양성 재설계·필사 전투 검증 편입

무적 처리량 SIM이 전투를 전혀 못 본다는 사각지대를 필사(mortal) 프로브로 실측해 두 결함을 찾아 고쳤다. (1) 기본 조우가 위협이 없었다 — BOT.CHAT은 HP 피해가 없어(큐 지연만) 가만히 서 있어도 안 죽었다. 중반부터 BOT.CHAT 웨이브에 POP.AD 슈터를 혼합(`1+turn/6`)해 실제 위협을 만들었다. (2) 태그 스쿨 4개 중 일부가 약하거나(관통·연사) 오히려 손해였다(확산 초안이 데미지 분산으로 킬 감소).

네 스쿨을 **전부 additive(never worse)한 뚜렷한 무기 정체성**으로 재설계했다: 확산(NETWORK=최근접 외 다른 적에 추가 탄)·다발(REPEAT=부채꼴 추가 탄)·연사(REPLAY=재장전 단축+관통)·내성(SAFE=무적시간). 각 스쿨은 기본 볼리를 뺏지 않고 더하기만 한다.

**필사 전투 측정을 selftest에 영구 편입(`test_combat_diversity`)**: 16 POP.AD 압박에서 스쿨별 생존·킬을 재고, 확산은 기본의 2배 이상 생존·전멸, 내성은 기본보다 오래 생존, 확산/다발은 기본보다 많이 처치, 연사는 최소 기본 이상(단조)임을 assert한다 — 무적 SIM이 못 보던 전투 다양성을 회귀 게이트로 승격. 실측: base 8킬/8.0초 사망 → NET 16킬/생존, REP 11킬, SAFE 9.7초, RPL 9킬. 7정책×1,000 SIM 불변, gcc 신택스·selftest 통과. 규칙 정본 [10](docs/10_MECHANICS.md) §4·[15](docs/15_CARDS.md) §9, 수치 balance.def(B2-전투). render.c 화면 검수는 Windows 게이트로 남긴다.

## 2026-07-19 — 덱→실시간 전투 상환·와이드 해상도·전투 정체성 가시화

도미니언식 덱빌딩을 뱀서/홀로큐어식 전투와 런 내내 연결했다. [15](docs/15_CARDS.md) §9의 "같은 계열 PROGRAM을 모으면 강해진다"는 상환이 최종 60초에만 있던 것을, **일반 방송 ON AIR에 상시 적용**했다: 네 태그 스쿨 소유 장수가 CARRIER 자동 전투의 연사(NETWORK)·다발(REPEAT, 부채꼴 추가 탄)·관통(REPLAY)·내성(SAFE) tier를 실시간으로 키운다(강도 1 기본, 2/4/6에서 tier 1/2/3 — §9 원칙 계승). 사는 카드가 최종전 형태뿐 아니라 매 구절 전투 스타일을 바꾼다. 수치는 `balance.def`(B2-전투) 정본. 규칙은 [10](docs/10_MECHANICS.md) §4·[15](docs/15_CARDS.md) §9에 정본화했다.

내부 해상도를 **320×240 → 400×240(5:3 와이드)**로 넓혀 홀로큐어식 회피·상황 파악 공간과 도미니언식 손패 한눈 파악을 확보했다. 아레나 경계·중앙/우측 정렬 요소를 전부 `SCREEN_W` 상대식으로 리팩터링하고, 손패 카드를 확대(59→74px)했다. EDIT·BREAK에 현재 전투 정체성 readout(`연사 II` 등)을 추가해 구매 결정과 전투를 잇는다.

무적 처리량 SIM은 태그 전투 스케일링에 불변(봇은 무적·echo는 OC 산출)이고, 넓어진 아레나로 적 동선이 바뀌어 7정책×1,000 승수만 소폭 이동(BIG_BAUD 158→151, ECHO_RUSH 858→871 등) — 전략 다양성 게이트(무지배 전략·5+ 정책 생존)는 동일 통과. gcc 신택스 체크 통과. 카드 역할(재화 CARRIER·액션 PROGRAM·승점 ARCHIVE·저주 NOISE)은 프레임 색·모서리·상태 라벨로 구분되고 각 역할대로 전투에 반영된다. render.c 실제 화면 검수는 Windows 빌드 게이트로 남긴다.

ON AIR에 다음 발동 프로그램 이름 문구(`> 카드명` / `편성 완료`)와 상단 카운트다운 슬라이버 막대(8초 구절 압박의 상시 시각화)를 더했다. 결정론 SIM(7정책×30) 회귀 동일 통과, gcc 신택스 체크 통과. render.c 런타임 드로잉의 실제 화면 검수는 Windows 빌드 게이트로 남긴다.
