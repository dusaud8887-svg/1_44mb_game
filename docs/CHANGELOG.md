## 2026-07-14 — 코드 리팩토링 라운드 1

- 밸런스 상수 정본화: 모든 튜닝 수치를 명명 상수로 추출, `card_now`/`attack_card` 피해량 이중 기재 제거. 동작 불변(selftest 결정 출력 동일).
- **MIRROR 지침 수정 적용**: `+1/장 최대 12` → `+2/장 최대 16`. selftest MIRROR 스모크를 9구매 제약 덱(19장, 보너스 16 단언)으로 교체 — 기존 테스트는 12구매(불가능 경제)로 통과해 증명력이 없었다.
- DEV 계측: playtest.csv에 `cheated` 컬럼 추가(F5~F8 사용 시 1). 구 스키마 로컬 로그 삭제.
- 첫 NODE 도움말에 조각 카드 회색→자홍 미리보기 구현(10 §7-1 약속 이행, 리스크 "조각 구매 기피" 1차 대응).
- **SIM 몬테카를로 하니스 구현**: 구매 정책 4종 × 조기/강제 × 30시드를 무적 헤드리스로 검증, 수용 기준 assert화. 첫 실측: 전 경로 성립, 최고 점유 30%, UTIL 경로 최약(~48%) — 유틸 가격·효과를 최우선 관찰 대상으로 지정.
- **3음 모티프 구현(W5 선행)**: SFX 보이스에 2노트 시퀀스 확장. 에코 E4–G4–B4(런 시작, 승리는 옥타브 위), 시크 역방향(엘리트·PATCH), 제로 B4 반복(GO LIVE·FORMAT 75% 경고 신설). 모뎀 발사음 음고 역전(등급 높을수록 낮게) — 문서 요구와 반대였던 것 수정.
- **G2 대조 빌드 2종 구현**: `build.bat gun`(FIXED_GUN — 덱·상점 없는 고정 총, 60초 생존 승리) / `build.bat dummy`(NO_THREAT — 접촉 피해 제거). 구 스펙 §15-0 반증 실험의 실행물.
- **인지 패스(perception pass)**: 자동 진행이 인지를 앞지르는 지점 8곳 수정 — 셔플 0.3초 정지, 산 카드 첫 귀환 NEW 표시+귀환음, 무음 조각 전용 틱음+신호 펄스(기존엔 공격음·궤적선이 잘못 출력), DEAD AIR 손패 교체 여유(LIVE 공식 불변), 조합 예고선, NODE `접속 대기` 예고, 구절 종결음, SEEK 대상 강조. DEFRAG 대상 선택에 ESC 취소 추가.
- **치명 교착 버그 수정**: 엘리트 처치의 BAD 제거가 손패 마지막 1장을 지우면 카드 순환·상점이 영구 정지하던 잠복 버그. 손패 공백 시 자가 회복으로 변경, 회귀 테스트 추가.

## 2026-07-14 — v3.0 문서 재구성

**설계 변경**
- MIRROR 지침: 실전 최대 덱 19장 검산으로 도달 불가 확정. `+1/장 최대 12` → `+2/장 최대 16` 시드값 제안, SIM 검증 후 적용(20 §결함-1). selftest MIRROR 스모크를 9구매 제약 덱으로 교체 예정.
- 헤드리스 SIM(스크립트 구매 정책 4종 몬테카를로) P0 도구로 신설(20 §SIM). "봇 AI 컷"과 구분 — 이것은 AI가 아니라 수식 검증이다.
- 게이트 신규 항목 3건: G1 NODE 템포(중단 기준·A/B 대안 포함), G2 SEEK 효용 설명, G2 서사 도달률(50 §3).
- playtest.csv에 `cheated` 컬럼 추가 예정 — 현행 로그에 치트키 세션이 섞여 밸런스 집계 오염.
- 3음 모티프 구체화: E4–G4–B4 정방향/역방향/단음(40 §4).
