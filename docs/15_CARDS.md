# 15 — 카드 설계

카드별 역할·형태·상호작용의 정본. 가격·수치·킹덤 보장 조건은 [20_BALANCE.md](20_BALANCE.md) B2-카드에만 산다. 실행 규칙(해석 순서·반올림·LINK 판정)은 [10_MECHANICS.md](10_MECHANICS.md) §14. 아이콘·이펙트 제작 규격은 [41](41_PIXEL_ART.md), 표시 규칙은 [45](45_UI_UX.md) §2.

## 0. 카드 개성 원칙

**카드 하나는 최소 두 개 이상의 차원에서 달라야 한다**: 공간 형태 / 시간 역할 / 덱 역할 / 경제 역할 / 메아리 역할. **피해량만 다르면 합치거나 제거한다.** V1 진단("카드가 대부분 탄환 수·피해량·관통·범위 변형으로 귀결")의 처방이다.

카드 시각 문법 — 음소거 영상에서도 발동 카드가 구분되어야 한다:

| 카드 | 화면 형태 |
|---|---|
| 2400 | 작은 사각 패킷 |
| 14K | 관통 패킷 열 |
| 56K | 적과 적을 잇는 지속 회선 |
| MULTI | 분기선 (실행 카드 사이 청록 이중 회선) |
| CACHE | 에코 주변을 공전하는 카드 잔상 |
| MACRO | 이전 효과의 반투명 재생 |
| FIREWALL | 사각 프레임 벽 |
| PREFETCH | 덱에서 끌려오는 고스트 카드 |
| MARKER | 적 위 주소 노드·번호 |
| SURGE | 노드 연결 네트워크 |
| CHECKSUM | 붉은 오류를 흰 픽셀로 복구 |
| CHAT | 글리프·말풍선 군집 |
| VOICE | 동심원 음파 |
| CLIP | CRT 프레임 절단 |
| NOISE | 죽은 픽셀·슬롯 노이즈 |
| NØA 계열 | 자홍 복제·프로필 군집 |
| SEEK 계열 | 호박 케이블·보관 태그 |

## 1. 타입과 공급군

| 타입 | 역할 | CUE | BAUD | 메아리 |
|---|---|---|---|---|
| CARRIER | **TX(자동 공격) 또는 RX(BAUD) 양자택일** — [10](10_MECHANICS.md) §3-1, ADR-0007 | 소비 안 함 | RX일 때만 | — |
| PROGRAM | 액션·엔진·공간 전투 | 보통 1 | — | — |
| ARCHIVE | 현재 부담, OPEN CHANNEL의 힘과 엔딩 | 일반 방송 발동 불가 / OC에서 0 | — | 청록 |
| NOISE | 손패·덱 오염 | 발동 불가 | — | — |
| REACTION | 피격·조건 반응 (P1+ 보류) | 0 | — | — |
| SPONSOR | 노아의 즉시 보상 | 카드별 | — | 자홍 |
| CACHE(시크 계열) | 보관·순환 개선 | 1 | — | 호박 |
| SERVICE | BREAK 즉시 사용, 덱 미편입 | — | — | 카드별 |

공급 출처: **BASE**(항상 존재) / **SESSION KINGDOM**(이번 런 PROGRAM 5종 — Kingdom은 타입이 아니라 공급군이다) / **ARCHIVE** / **SERVICE** / **EVENT**(노아·시크·시간층 조건 카드).

### 상호 견제 — 삼각(사각) 경제

- **CARRIER 과다** → 생존·구매력은 좋지만 최종 메아리·엔진·후반 장악력 부족. (Big Money 기준선 = BIG BAUD 전략: 안정적이되 최고점이 아니어야 함)
- **PROGRAM 과다** → terminal collision(CUE 부족), BAUD 부족, 실행 못 한 카드 증가.
- **ARCHIVE 과다** → 일반 방송 손패 정체, 구매력·생존력 감소, 조기 사망. **과소** → 64 완성 실패, 약한 최종 방송, 제한된 엔딩.
- **NOISE** → 순환 방해. CHECKSUM·SERVICE·(확장판) 오염 자원화의 대상.
- **SPONSOR** → 즉시 최강, 자홍·TREND 가속. **CACHE/시크** → 순환 안정, 호박 증가, "영구 재생 파일" 결말로 기울음.

## 2. 기본 CARRIER — TX/RX 양면

각 CARRIER는 매 턴 TX(공격) 또는 RX(BAUD) 중 하나로 지정된다. 표기: `TX 효과 / RX BAUD`.

### 2400 MODEM — 시작 전용

- TX: 2×2 작은 사각 패킷 한 발 + 짧은 청록 꼬리, 명중 시 1px 흰 점. 발사 간격이 명확히 느리다 — 박자가 다른 효과 아래에서도 들리는 낮고 마른 단일 사각파. / RX: BAUD 1.
- 역할: 초기 Copper — 초반에는 필요하고 후반에는 제거하고 싶은 약한 카드.
- 금지: 둥근 총알형 투사체 / 과도한 폭발 / 시작 카드의 화려한 잔광.

### 14K TURBO

- TX: 패킷 3개가 동일 간격의 한 열로 관통 — 관통할 때마다 뒷 패킷의 밝기가 한 단계 감소. **레이저가 아니라 전송 열**로 보이게. / RX: BAUD 2.
- 공간 차이: 2400 = 단일 목표, 14K = 좁은 직선 통로.

### 56K MAXIMUM

- TX: 에코와 대상 사이 1~2초 유지되는 얇은 회선(1px 끊긴 데이터선) 위로 사각 패킷이 흐른다. **대상이 죽으면 가까운 적에게 한 번 재접속.** 사운드: 낮은 캐리어 톤 + 짧은 핸드셰이크. / RX: BAUD 3.
- 후반 성장: OPEN CHANNEL에서 회선이 적뿐 아니라 메아리 링의 칸을 잠시 연결한다.

## 3. PROGRAM — 킹덤 풀

각 카드는 `ON AIR`(선택·수동 발동 시 주효과) / `OFF AIR`(선택하지 못했을 때의 약효과 또는 없음)를 가진다. OFF AIR를 전부 채우지 않는다 — 선택의 무게가 흐려진다([10](10_MECHANICS.md) §16-4).

### MULTI.FORK — Village

- ON AIR: **CUE +1** — 다음 PROGRAM을 이어서 선택 가능. 시각: 에코의 링에서 한 선이 두 갈래로 갈라져 현재·다음 PROGRAM 아이콘으로 연결. 두 효과는 동시가 아니라 **2~4틱 간격 연속 발동**으로 순서를 읽게 한다. 파티클은 분기점의 흰 픽셀 1개뿐 — 화면 전체 복제 연출 금지.
- OFF AIR: 다음 프로그램 준비 시간 소폭 감소.
- 역할: 자체 피해는 낮고 엔진을 여는 카드. terminal collision의 해답. NØA 모방: 완전 대칭의 자홍 분기 — 플레이어 양쪽에서 같은 공격을 동시 재현.

### CACHE.RAM — 보존과 콤보 준비

- ON AIR/EDIT: 손패 1장을 **보관**하고 그 자리에 1장 드로우. 보관 카드는 다음 턴 첫 프로그램으로 **150% 발동**.
- 시각: 선택 카드가 12×12 고스트 아이콘으로 접혀 에코 주변을 호박색으로 공전 → 다음 EDIT에서 원래 크기로 펼쳐짐 → 발동 시 원본보다 큰 잔상. 규칙: 캐시 오브젝트는 항상 같은 거리로 공전, 몸 관통 금지, 여러 개면 안쪽·바깥쪽 두 궤도. 시크 경로에서는 케이블 태그가 캐시 카드에 잠깐 붙는다.
- 역할: 좋은 카드 보존, 조합 준비, 손패 경계 전략. **호박 경로와 연결**(보관의 유혹).

### MACRO.REC — 형태 복제

- ON AIR: 직전 수동 PROGRAM/PAYLOAD의 **형태 전체** 재생(강도 70% 최근접 반올림). 시각: 화면이 1px 뒤로 미끄러졌다 원위치 → 직전 효과가 반투명 잔상으로 1~2프레임 늦게 재생, 시작점은 원본과 명확히 다르게.
- OFF AIR: 직전 CARRIER 공격의 작은 잔상 재생.
- 역할: 콤보의 정점. **에코의 MACRO는 불완전한 기록(픽셀 일부 누락) / NØA의 TREND MIRROR는 지나치게 완전한 대칭 자홍 복제** — 같은 기술 계보의 가치관 차이.

### FIREWALL.FRAME — 공간 통제

- ON AIR: 에코 주변 사각 창 테두리 3면 생성, 한 면은 열린 문. 닫힌 면에 닿은 적탄은 흰 정지 픽셀을 거쳐 청록 패킷으로 변환. 모서리에 작은 창 제어점(X 버튼 남발 금지).
- 공간 재미: **열린 방향을 적 쪽에 둘지 탈출 방향에 둘지** — 원형 무적막과 완전히 다른 위치·방향의 의미.
- REACTION 후보(P1+): 손패에 있을 때 큰 피해를 받으면 약한 벽 1면 자동 생성 후 격리. 저자극: 변환 플래시 → 테두리 펄스.

### PREFETCH — 덱 조작

- ON AIR/EDIT: 덱 위 3장의 반투명 고스트가 에코 앞에 계단처럼 나타남 → 1장이 현재 큐 뒤로 미끄러져 들어오고 나머지는 위로 되감김. ARCHIVE 선택 시 그 조각의 대표 색이 한 프레임 먼저 나온다(예고 25%).
- OFF AIR: 다음 카드 공개 가속. **아이콘과 애니메이션이 같은 문법**: "뒤의 세 장 중 한 장이 앞으로 건너온다."

### MARKER.TAG — cantrip 표식

- ON AIR: 최근접 다수 적에 `01 02 03` 주소 태그(태그별 테두리 모양도 다르게 — 번호가 안 읽히는 상황 대비) + 1장 드로우. 얇은 점선이 다음 연결 순서를 예고. 죽은 적의 번호는 즉시 재배정하지 않고 잠깐 빈 노드로.
- OFF AIR: 최근접 1체만 태그. 정보 우선: 화려한 링 금지 — 이미 에코 64링과 시크 링이 있다.

### SURGE.NET — 연쇄 페이로드

- ON AIR: 표식 적 사이 1px 회선 + 회선 위를 한 방향으로 흐르는 밝은 신호. 적이 죽으면 선이 끊겼다 다음 노드로 재접속 — **네트워크가 살아 움직이는 것이 성장 체감이다.** 최대 연결 수 제한(거미줄 금지). 표식 없으면 최근접 3체 임시.
- OFF AIR: 표식 1개 소모, 작은 낙뢰. MARKER→SURGE가 대표 LINK 쌍.

### CHECKSUM — 정화·반응

- ON AIR: 대상 영역을 한 줄씩 스캔(좌→우/상→하) — 빨강·회색 깨진 픽셀이 흰색을 거쳐 청록으로. NOISE 1장 비활성화 또는 **자홍 메아리 1칸 청록 복구.** 없으면 다음 두 카드 안정화.
- 금지: 힐링 초록 십자가 / 범용 스파클 / 의미 없는 코드 비.
- REACTION(P1+): MOD.MASK 공격 1회 무효. 역할: 자홍·오염 저항 — CLEAN SIGNAL의 축. NØA 모방: 가짜 관객을 복구·증식.

### DEFRAG — SERVICE (덱 미편입)

Kingdom PROGRAM에서 **제거**, BREAK 서비스로만: 구매 1회를 소비해 카드 1장 영구 삭제. NOISE 삭제 시 보너스. 이유: 압축이 "뽑혀야 쓰는 카드"가 되면 압축 자체가 운이 된다. 기회비용(이번 턴 성장 포기)이 명확해야 한다.

## 4. ARCHIVE — 무음의 승점

일반 방송: 손패를 막는다(발동 불가, PREFETCH 예고만). OPEN CHANNEL: CUE 0의 메아리 필살기로 반전([10](10_MECHANICS.md) §10).

| 카드 | 일반 방송 (무음의 질감) | OPEN CHANNEL | 강점 / 약점 |
|---|---|---|---|
| CHAT.LOG | 회색 말풍선, 드물게 해독 안 된 글자 1px 점멸 | 글리프·말풍선 군집이 적 사이를 튕김. 같은 적 반복 타격 시 글리프가 짧은 문장 조각으로 연결 | 다수 처리·빠른 수급 / 단일 보스 약함 |
| VOICE.OGG | 중앙이 빈 회색 파형, 거의 안 들리는 carrier tick | 끊긴 호 여러 개로 구성된 동심원 음파 — 적탄 밀침·감속, 안전 공간, 지속 피해 | 군중 제어·생존 / 순간 폭발력 낮음 |
| CLIP.20?? | 검은 썸네일과 잘못된 날짜. 선택해도 화면이 한 프레임 비어 있음 | 4:3/1:1 크롭 프레임 생성 — 내부 시간 2~4틱 고정, 테두리가 닫히는 순간 큰 피해. 잘린 영역 안에 과거·미래 배경 한 장면이 아주 짧게 | 엘리트·보스 / 느리고 다수 약함 |

- CHAT 글리프는 읽는 텍스트가 아니라 `□`·`…`·한글 자모 조각처럼 보이는 그래픽으로 제한 — 실제 UI 텍스트와 충돌 금지.
- VOICE 사운드는 절차적 음정·숨·노이즈의 결합 — **사람이 말한 것처럼 들리기 직전에 끊기는 것**이 세계관과 용량 모두에 맞다.
- CLIP 금지: 무조건적 전화면 필살기 / 조작을 끊는 긴 컷신.

**ARCHIVE의 종류와 비율이 최종 방송 형태와 엔딩을 동시에 결정한다**(§8). "무엇을 몇 장 사는가"가 빌드이자 서사 선택.

## 5. NOISE / PATCH

- **NOISE(BAD 계열)**: 발동 불가 슬롯 점유. MOD.MASK 등이 삽입. 상한은 B2-시작. 확장판 보류: 오염을 자원으로 쓰는 DIRTY BROADCAST.
- **PATCH.TMP**: 엘리트 보상 등으로 유입되는 일회성 정화·전화면 효과 후 자기 폐기(V1 유지).

## 6. NØA SPONSOR — 유혹은 진짜다

조건부로 BREAK에 나타난다. **즉시 효과는 실측 최강이어야 하고, 카드도 가장 세련되고 사용하기 편해야 한다** — 못생기거나 명백히 저주처럼 보이면 유혹이 아니다. 시각: 완전 대칭 프레임, 자홍 프로필 원이 정확한 간격으로 에코 주위를 회전, 공격이 가장 보기 좋은 타이밍에 자동 정렬. 사용할 때마다 링의 청록 한 칸에 얇은 자홍 이중선이 덧씌워진다. 사운드: 완벽한 알림음 + 깨끗한 화음 + **거의 들리지 않는 다중 호흡**. 공통 대가: 자홍 모방 메아리 + TREND 학습 가속 + PERFECT AUDIENCE 엔딩으로 기울음.

| 카드 | 즉시 효과 | 대가 |
|---|---|---|
| NØA BOOST | 비용 0. 이번 턴 CUE +1 | 자홍 +2 |
| AUTO CHAT | 저비용. 이번 턴 BAUD 보너스 | 자홍 +1, 처치 시 가짜 채팅 연출 |
| RECOMMEND | 특정 PROGRAM 할인 | 그 카드가 TREND 후보 등록 |
| PERFECT CUT | 화면 적탄 전부 삭제 + 넉백 | 자홍 +2, 직전 PROGRAM을 노아 복제 목록에 저장 |

## 7. SEEK / CACHE 계열 — 보관의 경제

- **시크 거래**(BREAK, [10](10_MECHANICS.md) §6): 카드 1장 영구 보관 → 덱 압축 + 호박 메아리. 보관 카드는 엔딩·로그에 흔적("이 런에서 시크가 보관한 것: …").
- CACHE 계열 카드: 카드·메아리를 손패 밖 저장 영역에 보관, 순환·안정성 개선, 호박 생성.
- 위험(의도된 것): 보관된 것은 청록으로 송출되지 않는다. 보관 수가 많으면 LAST ARCHIVE — **현재의 에코보다 보관된 에코가 우선되는 결말.** 순환 이득과 결말 대가를 한 카드에 싣는다.

## 8. 최종 방송 프로토콜 — ARCHIVE 다수 타입 × PROGRAM modifier

OPEN CHANNEL 진입 시 덱 구성으로 결정된다. "이번 런의 필살기를 내 덱이 만든다."

```text
ARCHIVE 다수 타입          PROGRAM 태그 modifier
CHAT 다수  → CHATSTORM     MULTI/CACHE      → REPEAT  (반복·복제)
VOICE 다수 → RESONANCE     MARKER/SURGE     → NETWORK (연결 확산)
CLIP 다수  → FRAMECUT      FIREWALL/CHECKSUM→ SAFE    (방어 공간·정화)
균형       → OPEN ECHO     MACRO/PREFETCH   → REPLAY  (이전·다음 구절 참조)
                            (세 형태 순환)
```

조합 예:

- `CHATSTORM + NETWORK` — 채팅 글리프가 표식 적 사이를 연쇄 이동한다.
- `RESONANCE + SAFE` — 음파가 적탄을 밀어내며 안전 지대를 만든다.
- `FRAMECUT + REPLAY` — 화면 절단이 같은 위치에 한 번 더 재생된다.
- `OPEN ECHO + REPEAT` — 세 ARCHIVE 형태가 5장 구절 단위로 순환·반복된다.

modifier는 덱에서 해당 태그 PROGRAM이 가장 많은 것 하나 `[시드값]`. **실제 구현은 핵심 효과 3~4개 × 수정자 4개지만, 플레이어에게는 여러 최종 빌드가 보인다.** 구현은 기존 이펙트 파라미터 변형으로 — 전용 이펙트 신작 최소화([30](30_TECH.md) §6).

## 9. 아이콘 — 16×16 재설계

V2에서 카드 아이콘은 **16×16 2bpp로 전면 재설계**한다(V1 12×12는 참고 자료, [41](41_PIXEL_ART.md) §1·ADR-0008). 설계 공식: `80% 기능의 주 실루엣 / 15% 방향·순서·시간 보조 기호 / 5% 타입·세력 포인트`. 예 — PREFETCH는 화살표가 아니라 "뒤쪽 작은 카드 3개 + 앞으로 건너오는 카드 1개 + 짧은 이중 화살촉".

- 글자 사용 기준: `2400/14K/56K`처럼 숫자가 세계관과 기능을 함께 설명할 때만. 금지 — 카드명을 알아야 해석되는 단일 문자(`M`,`F`,`P`), 16×16 안의 영문 단어, 의미 없는 육각형·회로·번개.
- 검수 순서: ① 16×16 실크기 → ② 1색 실루엣 → ③ 회색조 → ④ 카드명 없이 기능군 맞히기 → ⑤ 같은 계열 한 줄 혼동 검사 → ⑥ 95퍼센타일 혼잡 화면 위 → ⑦ 상태 기호(선택·봉인·지연) 부착 후 원형 유지.
- V1에서 개념을 승계할 후보: 단계형 모뎀(2400/14K/56K), BAD의 큰 X, MULTI 겹친 카드, FIREWALL 벽, 자물쇠·선물상자·플로피. 재설계 우선: PATCH = 렌치 / MACRO = 동일 모양 2개+되돌림 화살표 / CACHE = 옆으로 밀린 저장 블록 층.
- 타입 구분은 색이 아니라 **프레임 모서리 형태**가 1차([45](45_UI_UX.md) §2). 색 분류는 보조: CARRIER = 청록 / 보관 = 호박 / ARCHIVE = 회색→3색 반전 / 오염 = 빨강 / SPONSOR = 자홍 / 현재 선택 = PAPER 테두리.
