# 15 — 카드 설계

카드별 역할·형태·상호작용의 정본. 가격·수치·킹덤 보장 조건은 [20_BALANCE.md](20_BALANCE.md) B2-카드에만 산다. 실행 규칙(해석 순서·반올림·LINK 판정)은 [10_MECHANICS.md](10_MECHANICS.md) §14. 아이콘·이펙트 제작은 [41](41_PIXEL_ART.md) §9.

## 0. 카드 개성 원칙

**카드 하나는 최소 두 개 이상의 차원에서 달라야 한다**: 공간 형태 / 시간 역할 / 덱 역할 / 경제 역할 / 메아리 역할. **피해량만 다르면 합치거나 제거한다.** V1 진단("카드가 대부분 탄환 수·피해량·관통·범위 변형으로 귀결")의 처방이다.

카드 시각 문법 — 음소거 영상에서도 발동 카드가 구분되어야 한다:

| 카드 | 화면 형태 |
|---|---|
| 2400 | 작은 사각 패킷 |
| 14K | 관통 패킷 열 |
| 56K | 적과 적을 잇는 지속 회선 |
| MULTI | 분기선 (실행 카드 사이 청록 이중 회선) |
| CACHE | 에코 주변을 공전하는 카드 잔상 |
| MACRO | 이전 효과의 반투명 재생 |
| FIREWALL | 사각 프레임 벽 |
| PREFETCH | 덱에서 끌려오는 고스트 카드 |
| MARKER | 적 위 주소 노드·번호 |
| SURGE | 노드 연결 네트워크 |
| CHECKSUM | 붉은 오류를 흰 픽셀로 복구 |
| CHAT | 글리프·말풍선 군집 |
| VOICE | 동심원 음파 |
| CLIP | CRT 프레임 절단 |
| NOISE | 죽은 픽셀·슬롯 노이즈 |
| NØA 계열 | 자홍 복제·프로필 군집 |
| SEEK 계열 | 호박 케이블·보관 태그 |

## 1. 타입과 공급군

| 타입 | 역할 | CUE | BAUD | 메아리 |
|---|---|---|---|---|
| CARRIER | 경제 + 자동 공격 + 안정성 | 소비 안 함 | 생성 | — |
| PROGRAM | 액션·엔진·공간 전투 | 보통 1 | — | — |
| ARCHIVE | 현재 부담, OPEN CHANNEL의 힘과 엔딩 | 일반 방송 발동 불가 / OC에서 0 | — | 청록 |
| NOISE | 손패·덱 오염 | 발동 불가 | — | — |
| REACTION | 피격·조건 반응 (P1+ 보류) | 0 | — | — |
| SPONSOR | 노아의 즉시 보상 | 카드별 | — | 자홍 |
| CACHE(시크 계열) | 보관·순환 개선 | 1 | — | 호박 |
| SERVICE | BREAK 즉시 사용, 덱 미편입 | — | — | 카드별 |

공급 출처: **BASE**(항상 존재) / **SESSION KINGDOM**(이번 런 PROGRAM 5종 — Kingdom은 타입이 아니라 공급군이다) / **ARCHIVE** / **SERVICE** / **EVENT**(노아·시크·시간층 조건 카드).

### 상호 견제 — 삼각(사각) 경제

- **CARRIER 과다** → 생존·구매력은 좋지만 최종 메아리·엔진·후반 장악력 부족. (Big Money 기준선 = BIG BAUD 전략: 안정적이되 최고점이 아니어야 함)
- **PROGRAM 과다** → terminal collision(CUE 부족), BAUD 부족, 실행 못 한 카드 증가.
- **ARCHIVE 과다** → 일반 방송 손패 정체, 구매력·생존력 감소, 조기 사망. **과소** → 64 완성 실패, 약한 최종 방송, 제한된 엔딩.
- **NOISE** → 순환 방해. CHECKSUM·SERVICE·(확장판) 오염 자원화의 대상.
- **SPONSOR** → 즉시 최강, 자홍·TREND 가속. **CACHE/시크** → 순환 안정, 호박 증가, "영구 재생 파일" 결말로 기울음.

## 2. 기본 CARRIER

### 2400 MODEM — 시작 전용

BAUD +1. 작은 사각 패킷 한 발씩의 자동 스트림. 초기 Copper — 초반에는 필요하고 후반에는 제거하고 싶은 약한 카드. 공격 이펙트는 작고 명확하게.

### 14K TURBO

BAUD +2. 짧은 패킷 열, 관통. 안정적 중급 경제.

### 56K MAXIMUM

BAUD +3. **적과 적을 잇는 지속 회선** — 단순 큰 탄환이 아니라 잠시 남는 통신선으로 위상 차이를 보여 준다. 비싸고 강한 경제·전투 겸용(PAYLOAD 태그).

## 3. PROGRAM — 킹덤 풀

각 카드는 `ON AIR`(선택·수동 발동 시 주효과) / `OFF AIR`(선택하지 못했을 때의 약효과 또는 없음)를 가진다. OFF AIR를 전부 채우지 않는다 — 선택의 무게가 흐려진다([10](10_MECHANICS.md) §16-4).

### MULTI.FORK — Village

- ON AIR: **CUE +1** — 다음 PROGRAM을 이어서 선택 가능. 실행 카드 사이에 청록 이중 회선.
- OFF AIR: 다음 프로그램 준비 시간 소폭 감소.
- 역할: 자체 피해는 낮고 엔진을 여는 카드. terminal collision의 해답.

### CACHE.RAM — 보존과 콤보 준비

- ON AIR/EDIT: 손패 1장을 **보관**하고 그 자리에 1장 드로우. 보관 카드는 다음 턴 첫 프로그램으로 **150% 발동**.
- 시각: 보관 카드가 에코 주변을 공전, 다음 턴 시작 때 크게 복귀.
- 역할: 좋은 카드 보존, 조합 준비, 손패 경계 전략. **호박 경로와 연결**(보관의 유혹).

### MACRO.REC — 형태 복제

- ON AIR: 직전 수동 PROGRAM/PAYLOAD의 **형태 전체** 재생(동일 궤적·파동·벽·연결망을 반투명 잔상으로, 강도 70% 최근접 반올림).
- OFF AIR: 직전 CARRIER 공격의 작은 잔상 재생.
- 역할: 콤보의 정점. 노아 TREND MIRROR와 같은 기술 계보(적이 쓰면 자홍) — 복제라는 테마의 플레이어 측 표현.

### FIREWALL.FRAME — 공간 통제

- ON AIR: 에코 주변 사각 벽 3면 생성(열린 한 면으로 이동 가능). 적탄 차단, 조건부 친화 패킷 변환.
- REACTION 후보(P1+): 손패에 있을 때 큰 피해를 받으면 약한 벽 1면 자동 생성 후 격리.
- 역할: 수동 발동의 가치를 가장 잘 보여 주는 카드 — 어디에, 언제 세우는가.

### PREFETCH — 덱 조작

- ON AIR/EDIT: 드로우 더미 위 3장 공개, 1장 선택해 손으로. ARCHIVE를 가져오면 일반 방송에서도 25% 예고 효과.
- OFF AIR: 다음 카드 공개 시간을 앞당김.
- 역할: 순환 통제, ARCHIVE 예고 훅.

### MARKER.TAG — cantrip 표식

- ON AIR: 최근접 다수 적에게 주소 태그 + 카드 1장 드로우(cantrip). 다음 연결형 공격의 경로 예고선.
- OFF AIR: 최근접 1체만 태그.

### SURGE.NET — 연쇄 페이로드

- ON AIR: 표식 적 사이 지속 회선 네트워크. 적이 죽으면 다음 표식으로 이동. 표식 없으면 최근접 3체 임시 연결.
- OFF AIR: 표식 1개 소모, 작은 낙뢰.
- 역할: MARKER→SURGE가 대표 LINK 쌍.

### CHECKSUM — 정화·반응

- ON AIR: NOISE 1장 비활성화 또는 임시 PATCH 변환. **노아의 자홍 메아리 1칸을 청록으로 복구.** NOISE가 없으면 다음 두 카드 안정화.
- REACTION(P1+): MOD.MASK/QUAR.SEAL 공격 1회 무효.
- 역할: 자홍·오염 저항 — CLEAN SIGNAL 전략의 축.

### DEFRAG — SERVICE (덱 미편입)

Kingdom PROGRAM에서 **제거**, BREAK 서비스로만: 구매 1회를 소비해 카드 1장 영구 삭제. NOISE 삭제 시 보너스. 이유: 압축이 "뽑혀야 쓰는 카드"가 되면 압축 자체가 운이 된다. 기회비용(이번 턴 성장 포기)이 명확해야 한다.

## 4. ARCHIVE — 무음의 승점

일반 방송: 손패를 막는다(발동 불가, PREFETCH 예고만). OPEN CHANNEL: CUE 0의 메아리 필살기로 반전([10](10_MECHANICS.md) §10).

| 카드 | OPEN CHANNEL 형태 | 강점 | 약점 |
|---|---|---|---|
| CHAT.LOG | 작은 채팅 글리프·말풍선 군집, 다수 적 연쇄 | 빠른 메아리 수급 | 단일 보스 피해 낮음 |
| VOICE.OGG | 동심원 음파 — 적·적탄 밀어냄, 안전 공간, 지속 피해 | 생존과 수급 겸용 | 순간 폭발력 낮음 |
| CLIP.20?? | 화면 일부를 거대한 CRT 녹화 프레임으로 절단 | 엘리트·보스 결전 | 느리고 다수 처리 약함 |

**ARCHIVE의 종류와 비율이 최종 방송 형태와 엔딩을 동시에 결정한다**(§8). "무엇을 몇 장 사는가"가 빌드이자 서사 선택.

## 5. NOISE / PATCH

- **NOISE(BAD 계열)**: 발동 불가 슬롯 점유. MOD.MASK 등이 삽입. 상한은 B2-시작. 확장판 보류: 오염을 자원으로 쓰는 DIRTY BROADCAST.
- **PATCH.TMP**: 엘리트 보상 등으로 유입되는 일회성 정화·전화면 효과 후 자기 폐기(V1 유지).

## 6. NØA SPONSOR — 유혹은 진짜다

조건부로 BREAK에 나타난다. **즉시 효과는 실측 최강이어야 한다** — 함정으로만 보이면 유혹이 아니다. 공통 대가: 자홍 모방 메아리 + TREND 학습 가속 + PERFECT AUDIENCE 엔딩으로 기울음.

| 카드 | 즉시 효과 | 대가 |
|---|---|---|
| NØA BOOST | 비용 0. 이번 턴 CUE +1 | 자홍 +2 |
| AUTO CHAT | 저비용. 이번 턴 BAUD 보너스 | 자홍 +1, 처치 시 가짜 채팅 연출 |
| RECOMMEND | 특정 PROGRAM 할인 | 그 카드가 TREND 후보 등록 |
| PERFECT CUT | 화면 적탄 전부 삭제 + 넉백 | 자홍 +2, 직전 PROGRAM을 노아 복제 목록에 저장 |

## 7. SEEK / CACHE 계열 — 보관의 경제

- **시크 거래**(BREAK, [10](10_MECHANICS.md) §6): 카드 1장 영구 보관 → 덱 압축 + 호박 메아리. 보관 카드는 엔딩·로그에 흔적("이 런에서 시크가 보관한 것: …").
- CACHE 계열 카드: 카드·메아리를 손패 밖 저장 영역에 보관, 순환·안정성 개선, 호박 생성.
- 위험(의도된 것): 보관된 것은 청록으로 송출되지 않는다. 보관 수가 많으면 LAST ARCHIVE — **현재의 에코보다 보관된 에코가 우선되는 결말.** 순환 이득과 결말 대가를 한 카드에 싣는다.

## 8. 최종 방송 프로토콜 — ARCHIVE 다수 타입 × PROGRAM modifier

OPEN CHANNEL 진입 시 덱 구성으로 결정된다. "이번 런의 필살기를 내 덱이 만든다."

```text
ARCHIVE 다수 타입          PROGRAM 태그 modifier
CHAT 다수  → CHATSTORM     MULTI/CACHE      → ECHO    (반복·복제)
VOICE 다수 → RESONANCE     MARKER/SURGE     → NETWORK (연결 확산)
CLIP 다수  → FRAMECUT      FIREWALL/CHECKSUM→ SAFE    (방어 공간·정화)
균형       → OPEN RELAY    MACRO/PREFETCH   → REPLAY  (이전·다음 손패 참조)
```

조합 예:

- `CHATSTORM + NETWORK` — 글리프가 표식 적 사이를 연쇄한다.
- `RESONANCE + SAFE` — 음파가 적탄을 밀고 안전 지대를 만든다.
- `FRAMECUT + REPLAY` — 화면 절단이 같은 위치에 한 번 더 재생된다.
- `OPEN RELAY + ECHO` — 세 ARCHIVE가 5장 구절 단위로 반복된다.

modifier는 덱에서 해당 태그 PROGRAM이 가장 많은 것 하나 `[시드값]`. 구현은 기존 이펙트 파라미터 변형으로 — 전용 이펙트 신작 최소화([30](30_TECH.md) §6).

## 9. 아이콘 매핑 — 기존 16종 재사용과 신규

기존 V1 아이콘 중 잘 읽히는 것은 유지: 2400/14K/56K 단계형 모뎀, BAD의 큰 X, DEFRAG 분할 블록, MULTI 겹친 카드, FIREWALL 벽, TROJAN 선물상자, RANSOM 자물쇠, 플로피 상자.

재설계 권장 (원문 §10.4): WORM = 기어가는 몸+굽은 꼬리 / PATCH = 렌치 실루엣 / PREFETCH = `>>`+빈 슬롯 / MACRO = 동일 모양 2개+되돌림 화살표 / CACHE = 옆으로 밀린 저장 블록 층.

카드군 색 분류: CARRIER = 청록 / 유틸·보관 = 호박 보조 픽셀 / ARCHIVE = 회색 → 최종 단계에 청록·호박·자홍 / 오염 = 빨강 / 현재 선택 = 흰 테두리. 신규 제작 목록·예산은 [41](41_PIXEL_ART.md) §9.
