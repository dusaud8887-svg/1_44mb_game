# 40 — 아트·사운드·텍스트 (V2)

표현 계층의 정본. 픽셀 제작 규격·공정은 [41_PIXEL_ART.md](41_PIXEL_ART.md), 마케팅·후킹은 [42_VISUAL_HOOK.md](42_VISUAL_HOOK.md), 캐릭터 설정은 [06_CHARACTERS.md](06_CHARACTERS.md). 톤 배분 원칙 유지: **명랑 70 / 어긋남 20 / 어둠 10** — 계측값이 아니라 편집 원칙.

## 1. 시각 정체성 문장 (V2 정본)

> **일본 상업 캐릭터의 선명한 실루엣, 한국 90년대 PC통신의 건조한 서비스 언어, PC-98에서 영감을 받은 보석색 듀오톤, 방송과 관객 행동을 몸짓과 의상으로 번역한 직무형 모에, 아름다운 화면 한 프레임 사이에 나타나는 집단 관객의 그로테스크, 그리고 모든 시대에 잘못 찍히는 1997년.**

핵심 원칙 (금지가 절반이다):

- **화면 전체 글리치 금지. VHS 필터 남용 금지. 오류는 국소적** — 한 프레임, 한 숫자, 한 눈동자, 한 채팅 문장만 틀린다.
- 귀여움과 위협이 **같은 디자인 안에서** 뒤집힌다 (갭모에, [42](42_VISUAL_HOOK.md) §2).
- 교복·메이드·고양이귀·바디슈트 등 흔한 사이버 미소녀 기호 금지 / 국가 상징·일본 문자 금지 / 노출·장식 밀도로 만드는 후킹 금지 / 어느 실제 작품·서비스·OS도 재현하지 않는다.
- 캐릭터 핵심은 `비대칭 1곳 + 강조색 1개 + 반복 도형 1개`. 16×16에서 사라지는 설정은 그 크기의 핵심이 아니다 — 단, **표현 계층**([06](06_CHARACTERS.md) §0)이 크기별 역할을 설정으로 흡수한다.

| 캐릭터 | 색 | 도형 | 동사 | 실루엣 |
|---|---|---|---|---|
| 에코 일사사 | 청록(+빨간 LIVE 핀) | 끊긴 **64칸** 수신 링 | 보낸다 | 흰 비대칭 재킷, 청록 머리, 한쪽 수신 헤드셋 |
| 시크 웜 | 호박 | 깨진 버퍼 링·리본 케이블 | 보관한다 | 낮고 둥근 검정 (셸) / 공손한 아바타 (초상) |
| 노아 NØA | 자홍 | 수직 관객 베일·프로필 원 | 흉내 낸다 | 길고 수직인 검정 제복, 흰 장갑 |

모션 문법 (각 4프레임 상한, 반전·1px 오프셋·팔레트 교환): 에코는 새 손패 때 1px 튀고 링이 반 박자 늦게 따라온다 / 시크는 피격 시 가로 1px 눌리고 케이블이 반대로 휜다 / 노아는 걷지 않고 수직 1px 미끄러지며 베일의 프로필 아이콘만 흐른다.

## 2. 캐릭터별 V2 시각 변경

### 에코 — 링의 승격

유지: 청록, 비대칭 머리, 흰 재킷, 빨간 LIVE 핀, 끊긴 링(끊긴 방향 전 매체 통일). 강화:

- 링을 **64칸 수신 링**으로 승격 — 16×16에서는 8대구간 요약, HUD 스트립이 64칸 정밀 표시([10](10_MECHANICS.md) §8), OPEN CHANNEL에서 링이 화면 전체 UI로 확장.
- 링 색이 청록·호박·자홍으로 실시간 변화. 한쪽 수신 헤드셋. 재킷의 5개 큐 탭. 신호를 던지는 대표 포즈.
- 표정 아크(초상 추가분): 일반 → SPONSOR 사용(인공적 미소) → 48칸(눈썹 무너짐) → 64칸(눈이 먼저 반응). [41](41_PIXEL_ART.md) §9.

기존 초상의 개선점(원문 §8.1 유지): 한쪽 눈썹 1px 차이, 입 중심 1px 이동·한쪽 입꼬리, 옆머리-뒷머리 사이 어둠 1px, 사선 라펠, 체크 축소, LIVE 핀 위치 통일, 16×16 몸통 비대칭 강화.

### 시크 — 이중 정체성의 공식화

48×48 인간형 두 눈 초상 / 16×16 외눈 웜 셸 / 키아트의 어둠 속 눈 — 불일치가 아니라 표현 계층 설정([06](06_CHARACTERS.md) §2). 모든 표현의 브리지: 같은 방향으로 끊긴 호박 링, 리본 케이블, 완전히 읽히지 않는 한쪽 눈, 같은 송곳니/입꼬리.

V2 추가: 케이블에 훔친 메아리 칸·파일 태그가 매달림, 보관 카드 아이콘 공전, 호박 우세 시 시크 링은 완전해지고 에코 링은 조각남. LAST ARCHIVE 연출 = 에코의 프레임을 **봉인된 파일처럼 접는** 동작.

### 노아 — FORMAT/0 자산의 승계와 재해석 (ADR-0003)

승계: 자홍, 수직 실루엣, 흰 장갑, 히메컷, 반개한 눈, 정돈 습관, 쿠데레 얼굴 구조. 변경:

- 진행 막대(75%) → **MIMIC / RETENTION / AUDIENCE SYNC** 게이지로 재라벨.
- 종료 베일 → 댓글·프로필 아이콘이 수직으로 흐르는 **관객 베일**.
- 얼굴 주변 64개 프로필 원. 장갑은 화면 종료가 아니라 **채팅·표정·반응을 정돈**하는 동작.
- 보스전: 플레이어 카드 이펙트의 자홍 재현(TREND MIRROR — 렌더는 팔레트 교환+반전 재사용).

그로테스크 단계(진행 동기화, 항상 국소적·한 프레임): ① 프로필 원 몇 개가 눈처럼 깜박임 → ② 여러 닉네임이 같은 대사 → ③ 얼굴 일부 썸네일 격자 분열 → ④ 그림자가 빈 관객석 군집 → ⑤ 최종전: 몸 하나에 수백 개의 다른 지연으로 따라오는 관객 반응.

## 3. 팔레트와 화면 상태

논리 9색 유지 (확장 16색 상한). **링 3색 = 캐릭터 3색**이 그대로 게임 상태 언어다:

| 이름 | HEX | 용도 (V2) |
|---|---|---|
| BG | `100d18` | 배경 (OC: `130918`) |
| PANEL | `201c2b` | HUD·카드 바탕 |
| WHITE | `f2f0e6` | 본문·활성 카드·선택 테두리 |
| DIM | `7b7b86` | 보조·무음 ARCHIVE |
| CYAN | `4ddbc8` | 에코·실제 메아리·CARRIER |
| AMBER | `e5a84b` | 시크·보관 메아리·BAUD·셔플 |
| MAGENTA | `ed4f9a` | 노아·모방 메아리·OC 기조 |
| BLUE | `6da9e8` | TROJAN·보조 적 |
| RED | `e55b57` | 위험·NOISE·LIVE 핀 |

상태 대비: 일반 방송 = 청록/호박 기조, OPEN CHANNEL = 자홍/청록/흰색 경쟁. **같은 ARCHIVE 카드가 회색 `…` → 3색 반전으로 바뀌는 것이 제품의 얼굴이다.** 시간층별 변주는 팔레트 스왑으로([05](05_WORLD.md) §14).

## 4. 배경 디자인 — 80/15/5

```text
80% 조용한 어둠  /  15% 통신 구조  /  5% 시간 오류
```

반복 요소: 64분할 링 일부, 화면 밖으로 이어지는 케이블, 시대별 UI 프레임, 한 프레임의 잘못된 연도, 시청자 수와 채팅의 불일치, **자동 서비스는 동작하지만 사람 입력만 없는 화면**.

넣지 말 것: 전 화면 스캔라인, 상시 글리치, 의미 없는 코드 문자열, 모든 배경에 1997·플로피 반복, 복고 물건 박물관식 나열.

## 5. 사운드 정본

P0: `waveOut` 22.05kHz 모노, 사각파 2 + 노이즈 1 + SFX 1보이스. 음악이 불안정하면 SFX만 제출(원칙 유지).

### 3음 모티프 — 관계를 음으로

```text
에코   E–G–B 정방향 (상승 3음 뒤 짧은 빈 공간 — 관객의 답을 기다리는 자리)
시크   B–G–E 역방향 + 디스크 재탐색 노이즈 (새 멜로디가 아니라 기존 소리의 되감기)
노아   에코의 모티프를 완벽한 타이밍으로 재현하되, 여러 시청자 음색이 미세한 시간차로 겹친 다중 보이스
       — 초반에는 아름다운 코러스, 후반에는 같은 호흡이 너무 많이 겹쳐 불편해진다
```

기존 FORMAT/0의 `B 단음 반복`은 노아의 관리자 알림음·숨겨진 기저음으로 재활용. 해금 단서: 세 모티프가 같은 화음에서 갈라졌다는 사실([05](05_WORLD.md) §13).

### 턴 구조의 오디오 문법

- **EDIT**: 맑은 클릭(선택), 카드 슬롯 톡톡. 5장 손패 = 5펄스 한 구절.
- **ON AIR**: 선택 PROGRAM마다 고유 레이어 추가. CARRIER 발사음은 등급이 높을수록 낮고 두껍게(2400=300Hz → 56K=180Hz).
- **BREAK**: 모뎀 핸드셰이크·다운로드 음. 구매 카드 귀환 시 귀환음.
- **CLEANUP/셔플**: FDD 재탐색(시크음).
- **ARCHIVE**: 일반 방송에서 완전 무음 대신 **아주 작은 carrier tick** — 공격처럼 들리면 안 된다.
- **OPEN CHANNEL**: CHAT = 짧은 리듬·글리치 음절 / VOICE = 멜로디 중간음과 파동 / CLIP = 넓은 화음과 테이프 컷. 16·32·48 위상마다 레이어 합류(채널 수는 늘리지 않음 — 저음 합류 → 노이즈 리듬 → 옥타브 상승).
- **64**: 화음이 완전히 해결되기 직전 관객 소리. **엔딩 색에 따라 마지막 음이 달라진다.**

## 6. 텍스트·네이밍

원칙 유지: 한국어 먼저, ASCII는 작은 보조 라벨. 일본 문자·`~데스`류 흉내 금지. 혼합감은 와세이 에이고식 상업 합성어(`56K 맥시멈`)와 과잉 정중한 안내문의 온도 차로. 노출 면적: 한국어 80 / 한글 표기 외래어 15 / ASCII 5.

화면 표기(V2): 타이틀 `에코/144`, `오늘의 채널`, `TURN N/12`, `CUE ●`, `BAUD N`(병기: `다운로드 가능 N`), `NEXT NOISE`, `NØA is learning:`, `채널을 열까요?`, OFFLINE 막대, `VIEWERS` 모순 표기([05](05_WORLD.md) §5).

### 대사 — 정본 풀

캐릭터별 정본 대사는 [06_CHARACTERS.md](06_CHARACTERS.md) §1~3이 원천이다. 구현 규칙: 대사는 1.2초 한 줄, 무거운 문장 2연속 금지, 상황 트리거(등장·탈취·SPONSOR·48칸·엔딩)에 바인딩. V1 대사 9줄 중 유지: 에코 "다음 장면, 뒤로 부탁합니다", 시크 3줄 전부(정합), 포맷 줄은 노아 대사로 대체.

### 로그 조각 — 시간층 연동 개편

V1의 8개 로그 원칙(런당 밝은 것 1 + 무거운 것 1, 시드 선택) 유지하되 시간층별 풀로 재편 `[시드값]`: 1997 = PC통신 접속·자료실 안내 / 2006 = 방명록·플레이어 스킨 / 2026 = 추천·수익 창출 알림 / 2097 = 자동 서비스 정상 보고 속 STAFF 0. 무거운 로그는 [05](05_WORLD.md) §10의 공백을 겨냥하되 **답하지 않는다** — 도감·해금률 없음.

### 채팅 연출 — 메아리의 질감 (신규, [10](10_MECHANICS.md) §8)

메아리 1개 = 채팅 1줄. 청록 = 깨진 인간 흔적 + 제각각의 시대 타임스탬프 / 호박 = `[저장됨]` 라벨과 과거 날짜 / 자홍 = 닉네임만 다른 완벽히 동일한 문장. **이 질감 차이가 튜토리얼 없이 세 메아리의 윤리를 가르친다.** 노아 SPONSOR 사용 직후에는 자홍 라인이 눈에 띄게 늘어난다 — 화려함과 동질화가 함께 온다.

### 서사 전달률

미스터리의 운반체가 짧은 대사와 런당 로그 2개 + 채팅 질감뿐이므로 전달은 공짜가 아니다. G2′에 도달률 문항([50](50_PRODUCTION.md) §4). 미달 시 로그를 늘리지 않고 **노출 시점**(전투 밀도가 낮은 BREAK 직후 1초)으로 옮긴다.
