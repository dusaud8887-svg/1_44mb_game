## 1. 노스스타

> **표면은 밝고 매력적인 목록 밖 생방송, 틈새에는 모든 관객을 흉내 내는 집단 인격의 아름다운 호러.**

감정 배분 (V1의 70/20/10에서 개정):

```text
밝고 사랑스러운 생방송     65
설명하기 어려운 어긋남     25
명백한 호러·그로테스크     10
```

호러를 10%만 직접 보여 주는 이유: NØA가 처음부터 괴물로 보이면 "완벽한 관객의 유혹"이 사라진다. **정상 화면이 충분히 아름다워야 한 프레임의 이상이 강해진다.**

### 모든 주요 화면은 세 번 읽힌다

- **첫눈**: 에코가 귀엽고 기억된다 / 지금 무엇을 피하고 쓸지 명확 / 카드·효과가 색 없이도 구분 / 초점이 한 곳.
- **두 번째**: NØA가 친절하지만 지나치게 정확하다 / 시크가 적인지 조력자인지 모호 / 시청자 수와 채팅이 안 맞음 / 같은 기술이 자홍 완전 대칭으로 돌아옴.
- **세 번째**: 서로 다른 닉네임이 같은 오타 / 반사 화면에서 1997→2097 / NØA의 그림자는 빈 좌석 수백 개 / 시크 태그에 이전 런의 날짜 / 에코 링에서 항상 같은 한 칸이 비어 있음.

### 최상위 시각 원칙 10

1. 캐릭터가 필터보다 먼저 보인다.
2. 복고는 장식이 아니라 **세계가 정보를 전달하는 방식**이다.
3. 오류 하나에는 반드시 이야기상 이유가 있다.
4. 카드의 기능은 피해 숫자가 아니라 공간의 모양으로 보인다.
5. 화면이 화려해질수록 핵심 실루엣은 더 단순해야 한다.
6. 귀여움은 액세서리 수가 아니라 반복 행동에서 나온다.
7. 호러는 얼굴을 망가뜨리기보다 **완벽함이 지나치는 데서** 나온다.
8. 의도된 공백은 정보를 빼는 것이 아니라 여러 해석을 지지하는 단서 배치다.
9. 동일한 모티프는 캐릭터·UI·사운드·규칙에서 같은 뜻을 가진다.
10. 한 프레임을 정지해도 어떤 덱을 쓰는지 짐작할 수 있어야 한다.

## 2. 레트로와 2026년의 분담

**레트로가 담당**: 320×240 논리 해상도·정수 확대·레터박스 / 1·2·4bpp 자산·제한 팔레트·픽셀 글꼴 / 파일명·타임스탬프·접속 상태 / 짧고 의도적인 프레임 애니메이션 / 필요할 때만 디더 / 시대별 PC통신·홈페이지·플레이어·피드의 **정보 구조** / 사각파·노이즈·모뎀 효과음.

**2026년의 세련됨이 담당**: 썸네일에서도 읽히는 실루엣 / 일관된 로고·소셜 아이콘 / 우선순위 명확한 HUD / 짧지만 정교한 모션 타이밍 / 카드마다 다른 공간 점유 / 접근성 옵션 / 크롭 대응 키아트 / 모델 시트와 자산의 엄격한 일관성 / **플레이어 빌드가 보스 공격과 엔딩 이미지까지 바꾸는 통합 피드백** / 고해상 마케팅과 저해상 인게임의 역할 분리.

**사용하지 않을 가짜 레트로**: 상시 스캔라인 / 전 화면 VHS·RGB 분리 / 모든 배경의 코드 문자열 / 의미 없는 일본어·한자 / 고해상 생성 이미지의 모자이크 가짜 픽셀 / 배경 빈칸마다 플로피·`A:\` 반복 / 모든 메뉴의 두꺼운 복고 테두리 / 네온 청록·자홍만으로 주장하는 사이버펑크. **복고는 표면 효과가 아니라 "시간이 다른 데이터들이 서로 오해되는 방식"이다.**

## 3. 브랜드 — 제목·로고·팔레트·형태 문법

### 제목 체계

메인 제목 `에코/144 / ECHO/144`, 공식 부제 **`UNLISTED LIVE`**. `LAST LIVE`는 영구 부제에서 내린다 — 첫 스토리 에피소드명 / OPEN CHANNEL 직전의 방송 파일명 / V1 공모전판 버전명 / 게임 안에 보관된 이전 방송 제목 중 하나로 재배치.

### 로고 구조

`O`는 완전하지 않은 64칸 링 / `/`는 전파 절단선이자 시대 경계 / `144`는 플로피를 그리지 않고 제약을 암시 / 빨간 LIVE 핀은 로고 전체에서 **한 점만** / 기본 로고는 흰색·청록·빨강만 — 호박·자홍은 시크·NØA 경로 변형 로고에서만 침입. 타이틀은 비트맵 워드마크(시스템 글꼴 금지). 변형 세트 8종: 풀(한/영)·가로 마이크로·정사각 아이콘·청록 정상판·호박 보관판·자홍 모방판·**균형 엔딩판(빈 칸에 라벤더)**.

## 4. 캐릭터 시각 정본 (요약 — 전체 바이블은 [06](06_CHARACTERS.md))

브리지(모든 해상도에 필수):

```text
에코   끊긴 청록 링 / 비대칭 긴 머리 / 빨간 LIVE 핀 / 한쪽 수신기
시크   호박 버퍼 릴 / 읽히지 않는 한쪽 눈 / 리본 저장 케이블 / 날짜 태그
NØA    자홍 수직 댓글 베일 / 한쪽 흰 장갑 / 프로필 아이콘 환 / 완벽하게 정돈된 미소
```

- **에코**: 흰 비대칭 재킷(좌 라펠 직선·우 라펠 끊긴 원호, 한쪽 소매만 청록, 허리 옆 5장 CUE 탭, 안쪽 검은 하이넥) — 아이돌 드레스가 아니라 진행자·기술 스태프 사이의 기능복. **한쪽 수신기 = "보낼 수 있지만 아직 들을 수 없다"의 시각화** — OPEN CHANNEL에서 반대쪽 귀에 두 번째 수신광. LIVE 핀은 장식이 아니라 방송 상태 확인 물건: 불안하면 고치고, 피격 시 떨어질 듯 흔들리면 붙잡는다. NØA의 복제 핀은 지나치게 정확한 사각이거나 미세하게 색이 다르다.
- **시크**: 두 형태의 정식 분리 — 방송용 인간형 아바타(낮은 후드/스목, 한쪽 눈 가림, 목 뒤 포트에서 케이블 시작, 링=케이블 릴) / 실제 색인 프로세스(16×16 버퍼 셸, 외눈 렌즈, 케이블 끝이 먼저 화면에 들어옴). 남기는 질문: "인간형 얼굴은 시크가 보여 주는 것인가, 에코가 그렇게 기억하는 것인가." **케이블 물리 규칙**: 시작점 한 곳 고정, 굵기·커넥터 프레임 불변, 몸·옷 관통 금지, 임의 분기 금지.
- **NØA**: 3단계 — `FIRST MODERATOR`(깨끗한 초상, 자홍 억제, 믿을 만한 관리자) → `AUDIENCE`(환 16~32 분해, 베일 줄 속도 어긋남, 눈동자 안 작은 얼굴, 배경에 플레이어 최다 사용 PROGRAM 실루엣 반복) → `PERFECT AUDIENCE`(본체보다 그림자·프로필 벽이 크고, **얼굴은 오히려 가장 안정되고 아름다움**, 분노 대신 `RETENTION 100%`). 반개한 눈은 냉소가 아니라 **경청**. 피해를 받으면 얼굴보다 주변 프로필이 먼저 깨진다. 보스는 한 장이 아니라 레이어 합성: 본체 / 댓글 베일 / 장갑 커서 / 프로필 환 4~64 / 그림자 관객석 / TREND 복제품.

## 6. 사운드 정본

P0: `waveOut` 22.05kHz 모노 유지, 보이스 확장: **사각파 2 + 삼각파 1 + 노이즈 1 + SFX 2** `[시드값]`. 패치는 데이터다: `SynthPatch { wave, attack, decay, sustain, release, slide, vibrato, crush }` — 곡이 아니라 패치·음표·패턴을 저장한다([35](35_REFERENCES.md) §3 kkrieger).

### 3음 모티프 — 관계를 음으로

| 캐릭터 | 기본 모티프 | 시간 방향 | 불완전성 |
|---|---|---|---|
| 에코 | 상승 3음 (E–G–B) | 정방향 | **마지막 응답 자리가 비어 있음** |
| 시크 | 같은 3음 역방향 | 되감기 + 디스크 재탐색 | 시작음이 늦게 도착 |
| NØA | 같은 화음의 완전 정렬 | 예측·복제, 다중 보이스 미세 겹침 | **지나치게 정확함** |

NØA의 음악은 불협화음으로 무섭게 만들지 않는다 — 에코의 모티프를 너무 정확하고 풍부하게 완성해서 불편하게 만든다. 기존 `B 단음 반복`은 노아의 관리자 알림음으로 재활용. 해금 단서: 세 모티프가 같은 화음에서 갈라졌다는 사실([05](05_WORLD.md) §13).

### 카드·턴과 음악의 결합 — 덱이 편곡이다

5장 손패 = 한 마디. CARRIER = 박자 뼈대 / PROGRAM = 악기·리듬 변화 (CUE 발동이 악기 레이어를 켬) / ARCHIVE = 일반 방송에서 빈 박자(작은 carrier tick), OPEN CHANNEL에서 멜로디 / NOISE = 한 박자 누락 또는 비트크러시 / SPONSOR = 완벽한 자동 화음 + 자홍 레이어 / CACHE = 다음 마디로 음 하나 이월. 구절 마지막 카드는 낮은 종결음. **SYNC가 오르면 화음 레이어가 추가된다** — SYNC는 편곡 게이지다([10](10_MECHANICS.md) §4-1). 64 도달: 해결음 직전의 정적 → 엔딩별로 마지막 한 음만 다르다.

### 효과음 3층 구조

각 SFX는 `ATTACK(시작음) / BODY(물성) / TAIL(세계관 잔향)`로 설계한다. 예: FIREWALL = 클릭 / 낮은 사각파 문 닫힘 / 차단된 패킷 두 음. CACHE = 태그음 / 되감기 아르페지오 / 다음 손패 복귀음. NØA BOOST = 완벽한 알림음 / 넓고 깨끗한 화음 / **거의 들리지 않는 다중 호흡**. 카드별 지정은 [15_CARDS.md](15_CARDS.md).

## 7. 텍스트·네이밍

원칙 유지: 한국어 먼저, ASCII는 보조 라벨(한국어 80 / 한글 표기 외래어 15 / ASCII 5). 일본 문자·`~데스`류 금지. 혼합감은 와세이 에이고식 상업 합성어와 과잉 정중한 안내문의 온도 차로.

문자열은 처음부터 ID 기반(`strings_ko.tsv`: `ID<TAB>KO<TAB>EN(optional)`)으로 관리 — 확장판 현지화 대비([30](30_TECH.md) §7).

### 대사

캐릭터별 정본 대사는 [06_CHARACTERS.md](06_CHARACTERS.md)가 원천. 구현 규칙: 1.2초 한 줄, 무거운 문장 2연속 금지, 상황 트리거 바인딩(등장·탈취·SPONSOR·48칸·엔딩).

### 채팅 — 자유 생성이 아니라 저자 문법

AI·완전 무작위 문장 생성 금지(불일관 + AI slop). 작가가 만든 제한 문법 풀을 사용한다:

```text
[인사]        들려요 / 여기 어디예요 / 처음 봐요 / 아직 방송 중인가요
[시간 오류]   방금 1997이라고 뜬 건가 / 이 영상 어제 봤는데 / 이 채팅은 아직 안 썼어요 / 다음 방송이 먼저 끝났어요
[반응]        예뻐요 / 조금 무서워요 / 계속해 주세요 / 목소리가 두 번 들려요
```

**NØA의 가짜 계정 식별 문법** (같은 것을 공유): 같은 오타 / 같은 구두점 / 같은 0.2초 지연 / 같은 줄바꿈 위치 / 닉네임은 다른데 같은 문장 길이. 오타 풀도 데이터로 정의해 세력 단서로 쓴다 `[본 개정 구체화]`. 메아리 색과 채팅 질감의 대응(청록=깨진 인간 흔적+제각각 타임스탬프 / 호박=`[저장됨]` 라벨 / 자홍=완벽 동일 문장)은 [10](10_MECHANICS.md) §8. 노출 타이밍·밀도 규칙은 [45](45_UI_UX.md) §4.

### 로그 — 시간층 연동

런당 밝은 것 1 + 무거운 것 1, 시드 선택, 무거운 문장 2연속 금지 원칙 유지. 시간층별 풀과 환경 서사 소재는 [05](05_WORLD.md) §15. **새 로그로 공백에 답하지 않는다. 도감·해금률 없음.**

### 서사 전달률

운반체가 짧은 대사·로그 2개·채팅 질감뿐이므로 전달은 공짜가 아니다. G2′ 도달률 문항([50](50_PRODUCTION.md) §4). 미달 시 로그 추가가 아니라 **노출 시점 이동**(BREAK 직후 1초).
