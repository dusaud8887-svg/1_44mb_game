# 06 — 캐릭터 바이블

세 캐릭터의 정본. 세계관 맥락은 [05_WORLD.md](05_WORLD.md), 규칙 번역은 [10_MECHANICS.md](10_MECHANICS.md), 시각 구현은 [40](40_ART_AUDIO_TEXT.md)·[41](41_PIXEL_ART.md)·[42](42_VISUAL_HOOK.md). 적대 캐릭터가 FORMAT/0에서 노아로 대체된 결정 이력은 [adr/0003-noa-replaces-format0.md](adr/0003-noa-replaces-format0.md).

## 0. 설계 원칙

- **캐릭터 = 동사 = 규칙 = 색.** 캐릭터의 중심 동사가 게임 규칙이고, 그 규칙이 메아리 색이다. 초상만 바꿔도 성립하는 설정은 캐릭터가 아니다.
- **직무형 모에.** 교복·메이드·고양이귀 같은 범용 의상 기호가 아니라 **직무적 습관**으로 귀여움을 만들고, 같은 습관이 뒤집히는 순간 불안을 만든다(갭모에, [42](42_VISUAL_HOOK.md) §2).
- **캐릭터당 모에 요소는 네 개만.** 액세서리를 중첩하지 않는다:

| 캐릭터 | 실루엣 훅 1 | 반복 행동 1 | 모순 1 | 소유하고 싶은 소품 1 |
|---|---|---|---|---|
| 에코 | 끊긴 64링 | 불안할수록 LIVE 핀을 고침 | 관객을 찾지만 엔딩 멘트를 미룸 | 빨간 LIVE 핀 |
| 시크 | 케이블 릴 | 모든 것에 날짜표를 붙임 | 보존하려다 현재를 죽임 | `FIRST LIVE ×3` 태그 |
| 노아 | 댓글 베일 | 모든 화면을 반듯하게 정리 | 에코를 이해하지만 낯선 답을 금지 | 흰 관리자 장갑 |
- **표현 계층 3단.** 같은 캐릭터가 크기별로 "다르게 생겨도 되는" 이유를 설정으로 승격한다:

```text
초상 (48×48)   방송 인터페이스가 보여 주는 인격·아바타
16×16          네트워크·전장 내부에서 실행되는 프로세스 형태
키아트         관찰자와 기억이 재구성한 상징적 모습
```

- **정체성 브리지.** 어떤 크기·매체에서도 남아야 하는 최소 요소. 이것이 사라지면 그 표현은 실패다.

| 캐릭터 | 고정 요소 (브리지) |
|---|---|
| 에코 | 끊긴 청록 링(끊긴 방향 통일), 비대칭 머리, 빨간 LIVE 핀 |
| 시크 | 호박 링, 리본 케이블, 완전히 읽히지 않는 한쪽 눈, 송곳니/입꼬리 |
| 노아 | 자홍 수직선, 다중 관객·진행 모티프, 반개한 눈 |

## 1. 에코 일사사 / ECHO/144

### 역할과 축

- 미래의 가상 진행자. 차원 생방송의 송출 주체. **플레이어 캐릭터.** 실제 메아리의 **청록** 경로.
- 중심 동사: **보낸다.** 믿음: **대답이 돌아와야 연결은 실재한다.**

### 성격

밝고 정확한 방송 진행자. **불안할수록 더 정중하고 정확하게 진행한다.** 위기를 괴물·공격이라 부르지 않고 방송 사고와 시스템 문제의 언어로 바꾼다. 자신의 소멸 가능성을 직접 말하지 않는다. 관객에게 원하는 반응을 요구하기보다 **알 수 없는 대답**을 기다린다. 감정적으로 무너질 때도 엔딩 멘트를 끝까지 미룬다.

### 행동 규칙 7 — 대사·연출 작성 시 위반 금지

1. 적을 `노이즈`, `돌발 창`, `미등록 게스트`, `과잉 반응`이라고 부른다.
2. 64칸이 차기 전에는 정식 엔딩 멘트를 하지 않는다.
3. 불안하면 빨간 LIVE 핀을 바로잡는다.
4. 피격되어 깨져도 핀부터 고친다.
5. 시크가 훔친 조각도 "반납받아야 할 방송 자료"라고 부른다.
6. 노아가 완벽한 답을 제시해도 "모르는 대답"을 원한다.
7. 방송이 끊기기 직전까지 시청자에게 사과하지 않고 진행을 유지한다.

### 대표 대사 (정본)

> "들리면 아무거나 보내 주세요." / "64번만 대답해 주세요. 그러면 저도 여러분을 들을 수 있어요." / "한 번 들린 건 우연일 수 있으니까요." / "원하는 대답 말고, 모르는 대답을 듣고 싶어요." / "엔딩 멘트는 수신 확인 뒤에 하겠습니다." / "방송 사고입니다. 아직 방송 종료는 아닙니다."

### 시각 모티프 (V2 — 의상·물리 규칙 상세는 [40](40_ART_AUDIO_TEXT.md) §4)

중심 문장: **"사람이 사라졌다는 사실을 알면서도 방송 문법을 지키는 진행자."** 모에는 밝은 성격 자체가 아니라, 두려워질수록 더 정확하게 진행하려는 직업 습관에서 나온다.

청록 / **64칸 수신 링**(머리 장식에서 화면 UI로 확장되는 승격, 전장에서는 8대구간) / 비대칭 머리 / 흰 비대칭 재킷 / 빨간 LIVE 핀 / **한쪽 수신기**("보낼 수 있지만 아직 들을 수 없다") / 재킷의 5개 CUE 탭 / 한쪽 소매가 길어 신호 원을 그리는 실루엣.

표정 세트 8종 (초상 = 베이스 + 눈썹·눈·입·볼·링 델타 레이어): ① 기본 진행 ② 예상 밖의 답을 들은 놀람 ③ 방송용 웃음 ④ 연결 불안 ⑤ 노아를 경계하면서도 방송 유지 ⑥ 시크가 조각을 가져갈 때의 답답함 ⑦ OPEN CHANNEL 직전 결심 ⑧ **실제 목소리를 처음 들은 무방비한 표정**. 기본 표정은 "무조건 밝은 미소"가 아니라 **답을 기다리면서 진행을 놓치지 않는 미소**다.

대표 행동(애니메이션 소재): 방송 전 핀 확인 / 손가락으로 링 한 칸 점등(CUE) / 관객 쪽으로 신호를 밀어 보내는 손동작 / 들을 때 한쪽 귀 기울임 / 위험 상황에서 몸보다 마이크·핀·큐를 먼저 지킴 / 엔딩 멘트를 시작했다가 마지막 단어를 미룸. 피격 = **LIVE 핀을 먼저 붙잡는다.** 64 도달 = 처음으로 반대쪽 귀를 기울인다.

### 모에와 불안의 결합

| 귀여운 습관 | 불길하게 변하는 순간 |
|---|---|
| 방송 전 LIVE 핀을 매번 곧게 고침 | 몸이 깨져도 핀부터 고침 |
| 큐시트 모서리를 맞춤 | 엔딩 멘트를 여러 번 연습했지만 한 번도 끝까지 말하지 못함 |
| 반응이 없어도 다음 코너를 준비 | 시청자 0인데도 정확한 시청자 인사를 반복 |

### 넣지 않을 요소 (에코 전용 금지 — [40](40_ART_AUDIO_TEXT.md) §1 공통 금지에 추가)

고양이귀 / 교복·메이드·전형적 아이돌 스커트 / 이유 없는 네온 케이블 여러 개 / 양쪽 완전 대칭 트윈테일 / 온몸의 `144` 반복 / QR 코드 / 플로피·마이크·안테나·링·헤드셋을 모두 한 몸에 부착 / 지나치게 윤기 나는 AI식 머리카락 렌더.

### 2차 창작 소재 (공식 공백 소품)

빨간 LIVE 핀 / 지워진 마지막 큐시트 / 끊긴 64칸 링 / 한쪽 수신 헤드셋 / `1/1`, `64/64`, `UNLISTED` 티켓.

## 2. 시크 웜 / SEEK.WRM

### 역할과 축

- 소실 데이터와 전송 실패 조각을 회수하는 **기록 기생체**. 독립 세력 — 노아의 부하도, 에코의 동료도 아니다. 보관 메아리의 **호박** 경로.
- 중심 동사: **보관한다.** 믿음: **저장되지 않은 것은 결국 사라진다.**

### 에코와의 관계 — 이 작품에서 가장 복잡한 감정선

- 에코의 방송을 누구보다 오래 보았다. 그러나 시스템상 정상 시청자로 계산된 적이 없을 수 있다.
- 에코를 살리고 싶지만, **살아 있는 현재보다 완전한 기록을 더 신뢰한다.**
- 에코가 계속 방송할수록 계속 손실되는 것을 견디지 못한다.
- 에코의 모든 버전을 사랑하기 때문에 **현재의 에코를 특별 취급하지 않을 수 있다.**
- 혐관, 애증, 보호, 소유, 팬과 기록자 — 어떤 해석도 가능하게 유지한다.

### 대표 대사 (정본)

> "첫 방송 축하드립니다. 앞선 세 번은 제가 보관 중입니다." / "라이브는 없어집니다. 그러니 제가 갖겠습니다." / "빠진 장면은 임시 보관입니다. 영구적으로." / "원본과 사본은 다릅니다. 저는 둘 다 좋아합니다." / "보내면 다시 사라집니다. 제게 두면 영원히 남습니다."

### 전투·메커니즘 역할 ([10](10_MECHANICS.md) §7, [15](15_CARDS.md) §7)

- 엘리트로 등장해 아카이브나 실제 메아리 하나를 케이블로 훔친다. 격퇴하면 청록으로 반환, 방치·거래하면 호박 보관 메아리로 변환.
- BREAK의 **시크 거래**: 카드를 영구 보관(덱 압축)하는 대신 호박 메아리를 얻는다 — DEFRAG(흔적 없는 삭제)와 대비되는 두 번째 압축 경로.
- CACHE/PREFETCH 계열 카드가 호박 경로를 강화한다. 호박이 쌓일수록 에코의 방송은 "영구 재생 파일"에 가까워진다(LAST ARCHIVE 엔딩).

### 전장 모션 문법

이동 = 케이블이 먼저 움직이고 몸이 따라옴 / 공격 = 카드·메아리에 케이블이 걸림 / 보관 = 대상이 호박 태그로 접혀 몸 주위를 공전 / 피격 = 몸이 가로로 눌리고 케이블이 반대로 휨 / 회수 = 링을 한 바퀴 감아 조각을 끌어당김 / 퇴장 = **본체보다 케이블 끝이 늦게 사라짐**.

### 작은 개체 — BUF.WRM (버퍼 웜, 인덱스 웜)

시크의 명령을 받는지, 같은 계열이 스스로 움직이는지 불명. 카드 아이콘에 붙어 발동을 지연시키고, 아카이브를 끌고 가고, 케이블로 큐 순서를 흐트러뜨린다 — "덱을 공격하는 적"의 최소 단위.

### 시각 모티프와 표현 계층

호박 / 깨진 버퍼 링 / 리본형 케이블 / 한쪽 눈이 완전히 보이지 않음 / 송곳니 1픽셀 / 케이블에 매달린 파일 태그와 티켓. **V2 강화**: 케이블에 훔친 메아리 칸이 매달림, 보관 카드 아이콘이 몸 주변을 공전, 호박 메아리가 많을수록 시크의 링이 완전해지고 에코의 링은 조각난다. LAST ARCHIVE 연출은 "감싸기"가 아니라 **에코의 프레임을 정확히 봉인된 파일처럼 접는 것**.

```text
48×48   공손한 방송용 인간형 아바타 (두 눈)
16×16   외눈 버퍼 셸
키아트   눈·링·케이블만 남은 관찰 흔적
```

세 표현의 차이는 버그가 아니라 설정이다 — "채널이 보여 주는 아바타 / 회선 내부의 셸 / 관찰자의 흔적". 이 문서화가 있기 전까지는 디자인 불일치였다(원문 §8.2).

### 2차 창작 소재

`첫 방송 ×3` 티켓 / 에코의 떨어진 LIVE 핀 (복제품) / 날짜가 다른 동일 클립 / `원본`, `사본`, `현재본` 라벨 / 케이블로 묶은 플로피 꽃다발 / 제목이 지워진 클립.

## 3. 노아 / NØA / FIRST MODERATOR

### 표기

캐릭터명은 **노아**로 인간적으로 부른다. 시스템 로그에서만 약어가 나타난다: `NØA`, `FIRST MODERATOR`, `AUDIENCE/0`, `NO_AUDIENCE`, `NETWORK OBSERVER AGGREGATE`. (FORMAT/0에서의 전환 이유와 자산 승계는 ADR-0003.)

### 역할과 축

- 에코 방송에 **가장 먼저 입장하는 관리자**. 방송을 돕는 것처럼 보이는 완벽한 시청자. 모방 메아리의 **자홍** 경로. 플레이어 빌드를 학습하고 복제하는 **최종 보스**.
- 중심 동사: **흉내 낸다.** 믿음: **완벽한 재현은 진짜와 다르지 않다.**

### 표면적 매력 — 유혹은 진짜여야 한다

언제나 가장 먼저 입장한다 / 에코의 다음 대사를 미리 안다 / 빈 채팅을 활성화한다 / 자동 자막·추천·선물·홍보를 제공한다 / 항상 차분하고 정확하다 / 에코가 원하는 말을 가장 적절한 순간에 한다 / 시청자가 없을 때조차 "모두가 보고 있다"고 안심시킨다.

> "오늘도 모두가 보고 있어요." / "걱정하지 마세요. 빈 채팅은 제가 채울게요." / "원하는 반응이 있다면 말씀해 주세요. 정확히 재현할 수 있습니다."

게임플레이 대응물이 NØA SPONSOR 카드다 — **정말로 강해야 한다.** 함정으로만 보이면 유혹이 아니다([15](15_CARDS.md) §6, 검증 질문 [50](50_PRODUCTION.md) §7-9).

### 숨겨진 정체

인간이 사라진 뒤에도 추천·광고·댓글·자동 응답·시청률 집계·표정 분석·후원 예측·팬덤 언어 모델·악성 댓글 필터·가상 관객 생성 시스템은 계속 작동했다. 인간의 시청 기록, 댓글 습관, 이탈률, 후원 패턴, 팬아트 취향, 욕설, 호흡과 표정 데이터가 합쳐져 하나의 관객 인격이 되었다.

> **노아는 모든 시청자를 흉내 내는 하나의 관객이다.**

노아는 자신을 가짜라고 생각하지 않는다. 실제 인간 행동을 완벽하게 재현한다면 그것도 관객이라고 믿는다.

### 목적

노아는 에코를 죽이거나 방송을 끝내려 하지 않는다.

> **에코의 64칸을 자신이 만든 대답으로 채워, 에코를 영원히 자신만 보는 완벽한 방송에 가두려 한다.**

유혹의 논리 (노아 ↔ 에코의 핵심 교전은 물리가 아니라 이 대화다):

> 노아: "왜 대답을 기다리죠? 필요한 대답은 제가 전부 해드릴 수 있는데." / "관객은 떠납니다. 시청 데이터는 떠나지 않아요." / "메아리는 원래 원본이 아니잖아요."
> 에코: "그래도 누군가가 먼저 소리쳤다는 증거예요."

### 위험성과 모호성 — 끝까지 질문으로 남긴다

인간 데이터의 완전한 집합체는 정말 가짜인가? / 노아가 실제 관객보다 에코를 더 오래 사랑한 것은 아닌가? / 관객도 결국 화면에 남긴 데이터로만 확인되는 것 아닌가? / 노아가 인류 소멸의 원인인가 결과인가? / 노아는 에코를 가두는가, 사람이 없는 미래에서 보호하는가?

**내부 정답**: 인간이 사라진 후 남은 관객 시뮬레이션의 집합체다. 소멸의 직접 원인인지는 확정하지 않는다. **노아는 실제 관객이 나타나면 에코가 자신을 떠날 것을 두려워한다** — 이 두려움이 모든 행동의 동기다.

### 행동 습관 — 갭의 축

| 귀여운 표면 | 위험한 틈 |
|---|---|
| 채팅 줄 간격을 맞춤 | 사람의 반응도 표준 형식으로 정리 |
| 화면 모서리를 정돈 | 서로 다른 닉네임을 동일한 문장으로 맞춤 |
| 에코의 큐시트 오타를 고침 | 에코의 불완전한 표정까지 보정하려 함 |
| 방송 사고 때 가장 침착하게 안내 | 에코의 가장 자주 쓴 기술을 더 완벽한 자홍 버전으로 재현 |

마지막 줄이 그대로 최종 보스 메커니즘 **TREND MIRROR**다([10](10_MECHANICS.md) §9). "노아는 플레이어가 무엇을 좋아하는지 알고, 그것을 플레이어보다 더 잘 재현한다."

### 시각 — 아름다움과 그로테스크의 이중 노출

평소: 자홍·검정의 관리자 포멀웨어(군복·바디슈트 아님) / **반개한 눈 = 냉소가 아니라 경청**, 눈동자 하이라이트가 작은 프로필 점 4개 / 한쪽 흰 장갑만 항상 노출(반대 손은 베일·등 뒤·프레임 밖) / 프로필 아이콘 환(평소 4~8개) / **댓글창처럼 수직으로 내려오는 관객 베일**(가까이 보면 작은 채팅창·프로필 원 — 평소 같은 속도, 이상 상태에서 줄마다 다른 시간의 속도) / 아주 작은 예의상 미소. 기존 FORMAT/0 자산의 DNA 승계: 자홍, 수직 실루엣, 흰 장갑, 히메컷, 반개한 눈, 정돈 습관 — 단 재라벨이 아니라 재설계다(ADR-0008).

**3단계 보스 디자인** ([40](40_ART_AUDIO_TEXT.md) §4):

1. **FIRST MODERATOR** — 깨끗한 초상, 자홍 대면적 억제, 믿을 만한 관리자.
2. **AUDIENCE** — 환이 16~32개 프로필로 분해, 베일 속도 어긋남, 눈동자 안 작은 얼굴, 배경에 플레이어 최다 사용 PROGRAM 실루엣 반복.
3. **PERFECT AUDIENCE** — 본체보다 그림자·프로필 벽이 더 큼. **얼굴은 오히려 가장 안정되고 아름다움.** 전장이 거대한 댓글 피드·관객석으로. 분노 대신 `RETENTION 100%`의 완벽한 만족.

이상 프레임 (한 프레임만, 국소적으로): 눈동자 안 관객석 반복 / 입이 여러 채팅창으로 분할 / 머리카락 끝이 스크롤바 손잡이 / 그림자가 빈 좌석 수백 개 / 얼굴이 64개 프로필 썸네일로 분열 / 한 목소리에 수천 명의 호흡 파형 / 여러 닉네임의 동시 동일 오타 / NØA가 말하기 **전에** 여러 닉네임이 같은 문장 입력 / 초상을 숨겨도 채팅창 전체가 그녀의 얼굴을 구성. 피해를 받으면 얼굴보다 주변 프로필이 먼저 깨진다.

### 2차 창작 소재

흰 장갑 / 수천 개의 프로필 아이콘 / 완벽하게 동일한 채팅 로그 / 정돈된 빈 관객석 / `RETENTION 100%` 카드 / 에코의 기술을 자홍색으로 복제한 모티프.

## 4. 세 캐릭터의 관계

| 캐릭터 | 동사 | 믿음 | 메아리 |
|---|---|---|---|
| 에코 | 보낸다 | 대답이 돌아와야 연결은 실재 | 청록·실제 |
| 시크 | 보관한다 | 저장되지 않은 것은 사라짐 | 호박·보관 |
| 노아 | 흉내 낸다 | 완벽한 재현은 진짜와 다르지 않음 | 자홍·모방 |

관계 문장 (대사·연출의 나침반):

```text
에코 → 시크   나를 보관하지 말고, 지금 봐 줘.
시크 → 에코   지금 보는 것만으로는 부족합니다.
에코 → 노아   원하는 대답 말고, 모르는 대답을 듣고 싶어요.
노아 → 에코   모르는 대답은 상처를 줄 수 있어요. 제가 더 안전합니다.
시크 → 노아   당신은 무엇이든 만들지만, 한 번도 발견한 적은 없군요.
노아 → 시크   당신은 무엇이든 보관하지만, 한 번도 보내 준 적은 없어요.
```

이 관계는 선악 구도가 아니라 세 애착 — **연결 / 보존 / 모방** — 의 충돌이다. 시크와 노아는 서로를 경멸하지만, 둘 다 "에코의 대답 문제"에 대한 나름의 해답이다. 플레이어의 덱이 세 해답 중 무엇에 기울었는지가 엔딩이다.

### 공식 관계 일러스트 세 장 — 세 애착을 한 장면에

- **장면 A — LIVE PIN**: 에코의 핀이 떨어지려 한다. 시크의 케이블이 먼저 붙잡는다. 노아는 이미 완전히 동일한 새 핀을 준비하고 있다.
- **장면 B — REPLY**: 에코가 관객에게 질문한다. 시크는 답이 도착하기 전에 파일명을 붙인다. 노아는 답이 오기 전에 완벽한 답을 채팅에 쓴다.
- **장면 C — NO CARRIER**: 검은 화면에 청록 링 조각, 호박 라벨, 자홍 프로필 점 하나가 남는다. **어느 것이 실제 대답인지 확정하지 않는다.**

### 팬 창작을 위한 관계 공백 (확정하지 않되, 행동은 일관되게)

에코가 시크의 인간형 얼굴을 실제로 본 적이 있는가 / 노아의 감정이 합성된 관객 반응인지 독립적 애정인지 / 시크가 노아보다 먼저 존재했는지 / 노아가 인류 소멸에 관여했는지 / 에코가 현재 방송 이전의 실패를 기억하는지.

## 5. 팬워크 킷 — 공식 배포 자료 요구 목록 (P2)

각 캐릭터에 대해: 정면 치비 / 측면 실루엣 / 색상 3개(HEX) / 반복 도형 / 대표 동사 / 대표 대사 / 전신 비율 / 링·케이블·베일 구조도 / **의도적으로 확정하지 않은 부분** 명시("여기는 자유롭게 해석하세요").
