# PART C. 확정 기획 — 컨셉과 세계

## C-0. 컨셉 (v1.1 신규)

**로그라인**: 자정에 포맷이 예약된 1997년의 486 PC. 상주 프로그램 '지킴이.EXE'가 되어, 바이러스 물결을 뚫고 주인이 남긴 추억 파일들을 A드라이브 디스켓에 백업한다. 백업한 파일은 실행 큐를 막는 짐덩이 — 그러나 포맷이 시작되는 순간, 부팅 디스크가 발화하며 저장된 추억 하나하나가 빛의 탄환이 되어 터진다.

**에센셜 익스피리언스** (렌즈 #2 '본질적 경험'): 이 게임이 주려는 단 하나의 경험은 **"짐이 보물로 반전되는 순간"**이다. 8분간 '철컥'거리던 불발탄이 최후의 90초에 화면을 불태우는 그 반전. 모든 설계 결정은 이 경험을 기준으로 판정한다.

**테마 통일** (렌즈 '통일성'): 테마 = **저장(SAVE)**. 4원소 전부가 이 테마에 복무하는지 검사한 결과가 아래 매핑이다. 특히 **기술 원소의 제약(1.44MB)이 픽션 그 자체**가 된다 — "추억을 1.44MB에 담아라"는 이 게임의 이야기이자, 이 게임 파일의 물리적 현실이다. 심사자가 이 재귀를 발견하는 순간이 설계된 미소 포인트.

## C-1. 아이덴티티

- **제목**: SAVE.EXE / 장르: 실시간 덱빌딩 서바이버 / 싱글 / 1런 약 9.5분 (8:00 + 90초 클라이맥스)
- **플랫폼**: Windows x64 단일 exe [가정] / 320×240 16색, 정수배 업스케일
- **한 줄 경험 목표**: "8분간 참아온 불발탄이 90초의 불꽃놀이가 되는 반전을 몸으로 느끼게 한다"

## C-2. 승리 구조 — 포맷의 시간 (v1.1 확정)

**주 조건**: 8:00에 시스템 포맷 개시 → **덱의 모든 추억 파일(VP)이 성광탄으로 반전**되는 90초.
- 메모.TXT = 소폭발(20dmg r16) / 사진.JPG = 중폭발(45dmg r32) / 앨범.ZIP = 화면 절멸탄(전 화면 60dmg + 1초 정지 연출)
- **같은 카드, 같은 벨트, 같은 순환.** 구현은 카드 효과 테이블의 모드 플래그 1개. 8분간 '철컥'이던 그 자리에서 터진다 — 팩맨 파워펠릿의 반전(쫓기던 자가 사냥꾼으로)을 덱 시스템으로 재연.
- 90초간 사신 웨이브 무한 격화. **생존 시 클리어.** VP 화력이 없으면 여기서 죽는다 — "VP를 안 모으면 8분 뒤에 죽는 것밖에 안 됨"이 구조적으로 성립.
- 사망(전 구간) = 즉시 패배, 원버튼 "다음 킹덤 →" 재시작.

**보조 조건 (조기 개전)**: 앨범.ZIP 8장 전량 백업 시 즉시 포맷 발동. 도미니언 러시 전략의 부활 — 스폰 곡선이 덜 격화된 시점에 클라이맥스를 여는 대신 성장 시간을 포기. 스피드런 축 확보.

**딜레마 곡선**: 일찍 많이 사면 초중반 지옥 / 안 사면 최후 90초 사망 / 최적점은 킹덤·칙령마다 이동. 강제 시계는 별도 타이머가 아니라 뱀서 스폰 곡선 자체가 담당(늦은 그리닝 = 강한 총으로 짧게 버티는 도박).

**공정성 장치 (필수)**: 6:00부터 우상단에 "부팅 디스크 예상 화력: 부족/최소/충분" 게이지. 0VP 플레이어의 죽음이 기습이 아니라 예고된 청구서가 되도록. 첫 사망 시 정산 화면에 사인 명시("백업 파일 부족 — 포맷을 이기지 못했다").

**정산·랭크 (반복 동력 1)**: 점수 = VP 총량 × 포맷 중 처치 수 보정 × 잔여 HP 보정 → S/A/B/C. S랭크는 "충분" 게이지를 넘어 "과적" 상태로 생존해야 나오도록 [가정 — 튜닝].

**AUTOEXEC 칙령 (반복 동력 2)**: 매 런 1개 랜덤. 스코프 내 3종 확정: ①박물관(카드 종류당 +2VP) ②탑(소각 카드당 +1VP — 압축 플레이도 VP 경로가 됨) ③ZIP축제(덱 10장당 +2VP 추가). 30VP 상당으로 가는 *경로*를 매 런 비틀어, 킹덤 10종 읽기와 함께 "이번 판은 어떻게 채우지"를 리롤 동기로 만든다.

# PART G. 렌즈 감사 — The Art of Game Design 적용 (v1.1 신규)

Jesse Schell의 렌즈 체계로 v1.0을 감사한 결과와 반영 사항. (렌즈 번호는 판본에 따라 상이하므로 명칭 기준)

| 렌즈 | 진단 (v1.0) | 반영 (v1.1) |
|---|---|---|
| **4원소 (Elemental Tetrad)** | 메커닉스 90 / 기술 80 / 미학 60 / **스토리 10** — 사륜 불균형 | 컨셉 리워크(§C-0). 특히 기술 제약(1.44MB)을 스토리로 내재화해 원소 간 상호 강화 달성 |
| **본질적 경험** | "덱=탄창"은 메커니즘 서술이지 경험 서술이 아님 | "짐이 보물로 반전되는 순간"으로 재정의, 전 결정의 판정 기준화 |
| **통일성 (테마)** | 무국적 판타지 스킨이 테마 부재 상태 | 테마 '저장(SAVE)' 확정, 전 요소 매핑 검사 통과 |
| **감정** | 불발탄 = 순수 좌절로만 설계됨 | 좌절을 **투자**로 재프레임: 불발 '철컥'마다 부팅 디스크 게이지가 미세 상승하는 시각 피드백 — 같은 사건이 손실이자 적립이 되도록 |
| **호기심** | 벨트 UI가 예측 장치로만 기능 | 벨트에 포맷 후 모습(성광 오라) 프리뷰 — "이게 터지면 어떻게 될까"를 8분 내내 궁금하게 |
| **삼각성 (위험-보상)** | VP 구매가 유일한 삼각 선택 | 조기 개전(러시), 과적 S랭크, 탑 칙령(소각=VP)으로 삼각 선택 4축화 |
| **장난감** | 목표 제거 시 재미 미검증 | W1 게이트에 항목 추가: 이동+발사만으로 30초 만질 맛이 나는가 (게임필: 관성 微, 히트스톱 2프레임, 화면 흔들림) |
| **흥미 곡선** | 미설계 | §G-1 곡선 확정 |
| **문제 해결** | 킹덤 읽기 재미 확인됨 | 유지. 런 시작 시 자료실 목록 10종을 15초간 전체 공개("오늘의 자료실") — 도미니언의 판 읽기 30초 재현 |
| **간접 통제** | 없음 | 코인 젬 드랍 방향·상자 배치로 동선 유도, 포맷 직전 화면 중앙으로 사신 포위(클라이맥스 무대 연출) |
| **피드백** | 사운드 차등만 존재 | 카드 발동 = 벨트에서 카드가 물리적으로 날아가 소모되는 연출. 발사의 '출처'를 항상 가시화 |
| **스토리 (최소 서사)** | 없음 | 오프닝 3줄 고정 텍스트 + 정산 화면 1줄. 총 서사 예산 500바이트 — 이 게임에서 스토리는 프레임이지 콘텐츠가 아님 |

## G-1. 흥미 곡선 (9.5분 런)

```
관심도
  ▲                                              ★포맷의 시간
  │        보스1        보스2         ★예고게이지          (도파민 피크)
  │   ▲     ▲      ▲    ▲       ▲   6:00~   ▲▲▲▲▲▲▲▲▲
  │  첫상점  3:00        6:00                             ＼정산·랭크
  │▲0:30                                                    (여운)
  └──────────────────────────────────────────────────▶ t
   훅: 15초 자료실 공개(판 읽기) → 30초 첫 구매(첫 스파이크)
   골짜기: 상점 주기 30초가 소규모 파동을 강제 — 평탄 구간 없음
   상승: 보스(3:00/6:00) + 예고 게이지(6:00~)가 클라이맥스 사전 긴장 조성
   피크: 8:00 포맷 — 8분의 투자가 일괄 상환되는 유일무이 순간
```

Schell의 원칙대로 훅(초반 15~30초)과 피크(말미)를 먼저 고정하고 사이를 파동으로 채웠다. 잼 심사 환경(3분 시연)을 위해 **데모 배려**: 타이틀에서 ↑↑↓↓ 입력 시 6:30 시점 세이브된 쇼케이스 런 시작 [가정 — W6 여유 시에만, 예산 여유분 항목].
